# レトロ音源風VST「2686V」v3.1.0 README

(C)2026 CYROSS

## 1. はじめに

「2686V」(以降、合わせて「本ソフト」と表記します)は、レトロ音源(FM/SSG/ADPCM等)風の音を出すプラグイン「2686V」「2686VLight」「26V」「86V」「OPZX7S」とエフェクトプラグイン「2686VFX」を提供します。

## 2. 目的

DAW上で、「PC-9801-26」と「PC-9801-86」を再現したような曲を作りたかったけど眼鏡にかなうものがなかったので、プラグインを作ろう…としたはずだったが…

## 3. 概要

### 3-0. v3.1.0での追加・変更

- 変調の追加
  - **SSG HW PITCH ENV**
    - SSG HW AMP ENV と同じ波形を、音量ではなく音程へ当てる
    - MIN/MAX はセントで指定可能(-4800～4800、初期値 MIN=0 / MAX=1200)
    - ナッジボタン付属
    - 全チャンネル(FM含む)・全オペレーター・RHYTHMの全パッドで使用可能
    - インポート・エクスポート対応(`.ssgHwPEnv`)
  - **WT AMP MOD**
    - WT PITCH MOD と同じ変調波形を、音程ではなく音量へ当てる
    - MIN～MAXの範囲で変調(初期値 MIN=0.0 / MAX=1.0)
      - MIN/MAX は受け持つ波形・SLOT全てに適用
    - ナッジボタン付属
    - HuC6280 / FDS TABLE 対応
    - 全チャンネル(FM含む)・全オペレーター・RHYTHMの全パッドで使用可能
    - インポート・エクスポート対応(`.wtampmod`)
  - **FDS TABLE の名称を分離**
    - WT PITCH MOD 側を `FDS PITCH TABLE`、WT AMP MOD 側を `FDS AMP TABLE` と表記
- 全オペレーターへ展開
  - **SSG HW AMP ENV をオペレーターごとに搭載**
    - OPNA/OPZX7S は既存の SSG HW ENV と共存
  - **WT PITCH MOD をオペレーターごとに搭載**
    - 変調波形スロットもオペレーターごとに独立
  - いずれもインポート・エクスポート対応
- 2686VFX
  - **SSG HW PITCH ENV と WT AMP MOD を変調として追加**
- 画面
  - **簡易表示モード**
    - GUIの一部の区分を隠して、表示をシンプルにする機能
      - GUI表示だけの対応で、音には影響しない
    - SETTINGSタブの「ツールチップを表示」の上に設置。初期状態はOFF
    - 隠す区分はタブごとに設定
      - そのチャンネルが実機の機能として持つ区分は残す
        - SSGでは SSG HW AMP ENV、WT/WT2/WT+ では WT PITCH MOD が残る
      - 2686VFXは変調の枠を隠し、効果の枠は残す
    - ONにすると「簡易表示モードカスタマイズ(開閉)」が出現(初期状態は閉)
      - ここでONにした区分は簡易表示モードでも隠れない
      - 対象は AMP ENV / SSG HW AMP ENV / SSG SW AMP ENV / SSG SW AMP ENV[11] /
        WT AMP MOD / PITCH ENV / SSG HW PITCH ENV / SSG SW PITCH ENV[11] /
        WT PITCH MOD / LFO / MUL・DET / FIX / UNISON・HARMONY の13区分
    - 設定は設定ファイルへ保存
  - **ソフトウェア系区分の色分けを細分化**
    - 音量系→青、ピッチ系→ターコイズブルー、LFO→紫
    - OPTIONAL / UNISON・HARMONY / FIX / MUL・DET はシアンのまま
    - ハードウェア由来・音質系・その他系統は従来通り
  - **2686VFXのグループ配色を細分化**
    - FX(PCMビットクラッシャー含む)は従来通り青色系統
    - 変調系→赤色系統、LFO→緑色系統、その他→シアン系統
  - **区分の表示順を整頓**
    - HW由来とSW由来が両方存在するときは、HW由来の区分を上に表示
    - 音量系→ピッチ系→LFO の順にまとめて配置
- 修正
  - RHYTHMのパッドで、サンプリング周波数の変更が SSG HW AMP ENV へ伝わっていなかった
  - RHYTHMのパッドのパラメータファイルに WT PITCH MOD が含まれていなかった

### 3-1. 全体

※太字はv3.0.0からの新規・拡張

- 2686V:
  - ぼくのかんがえたさいきょうのレトロ音源VSTプラグイン
  - 当方の技術スタックでは100%再現するのは不可能だったため、不可能なら不可能なりに色々な音源風に聞こえるプラグインを作成した
  - また、目的は「曲を作ること」だったため、開発当初はコードはほぼ `Gemini3` による実装で執り行った。
    - **さらなる作業の効率向上のため、現在は `Claude Code` を使用**
- **2686VLight**:
  - 2686Vの軽量版
  - 2686Vからカーブ編集モードを省いて負荷を下げたもの
- **26V**:
  - 2686V Lightの構成を「PC-9801-26(K)」に近づけたもの
    - チャンネルはOPN、SSGのみ
- **86V**:
  - 2686V Lightの構成を「PC-9801-86」に近づけたもの
    - チャンネルはOPNA、SSG、RHYTHM、PCMのみ
    - 「ADPCM」のチャンネル名を「PCM」に変更、初期の音質を「4-bit PCM」に変更
    - RHYTHMチャンネルのパッド数を6に変更
      - パラメータファイルの互換を維持
- **OPZX7S**:
  - モダンFM音源オペレータ的位置のプラグイン
  - 2686VからOPZX7Sチャンネルとカーブ編集モードを抜き出した形で負荷を下げたもの
  - 標準でカーブ編集モードを適応(従来の線形モードをオミット)
- **2686VFX**:
  - 2686Vから派生したエフェクトプラグイン
  - 2686Vで使用していたエフェクトや変調をDAWのインストゥルメント・オーディオに使用可能
  - v2.x.xではオミットしていたが、v3.0.0へ変更するタイミングで復活
  - 2686VのFXペインをメインエフェクトとして搭載
    - UIもそれに合わせて調整
  - 2686VFXのみのFX、「PCMビットクラッシャー」を搭載
    - PCM系チャンネルの「QUALITY」をエフェクトとして活用
    - BITに関しては一部のみ利用可能
  - FXのかかり順変更はFX(PCMビットクラッシャー含む)のみ対応
  - 更に、2686Vの音源部分で採用していた以下の変調を追加
    - AMP ENV
      - SSG等で使用しているものがベース
    - SSG HW AMP ENV
      - SSG等で使用しているものがベース
    - SSG HW PITCH ENV
      - SSG等で使用しているものがベース
    - SSG SW AMP ENV11
      - SSG等で使用しているものがベース
    - PITCH ENV
      - SSG等で使用しているものがベース
    - SSG SW PITCH ENV11
      - SSG等で使用しているものがベース
    - WT PITCH MOD
      - WT/WT2/WT+等で使用しているものがベース
    - WT AMP MOD
      - WT/WT2/WT+等で使用しているものがベース
    - LFO
      - OPZX7Sで使用しているものがベース
    - MUL/DET
      - OPZX7Sで使用しているものがベース
      - 簡易版
    - UNISON/HARMONY
      - 音源チャンネルで使用しているものがベース
      - 簡易版
    - ※MIDI入力によるON/OFF切り替え
    - ※UIもFXグループ準拠に
    - ※バイパスは、各変調の他にメイングループでの一括設定が可能
  - 各FX・変調はのグループは横一列に並んでおり、スクロールバーで表示を切り替える形式

## 4. 特徴

※太字はv3.0.0からの新規・拡張機能

- 多彩なレトロゲーム音源(チャンネル)を楽しめる
  - ※各音源は「チャンネル」という単位で区分け
  - 各チャンネルはタブで切り替え可能
  - **ただし、1プラグインで同時に再生できるのは 1 チャンネルのみ**
    - DAWのトラックのほうが柔軟に構成を変えられるという思想で設計
- トラディショナルからモダンまで選び抜いた(創造した)数々のFM音源チャンネル
  - 多数のハードウェア由来FM音源チャンネル
    - 多数のFM音源オペレーターの再現に、設計思想を崩さない程度の拡張を追加
      - OPNA
        - OPNAの基本機能をカバー
        - N88-BASICで使用されたソフトウェアLFOを搭載
        - ハードウェアLFO、SSGハードウェアアンプエンベロープを搭載
      - OPN
        - OPNの基本機能をカバー
        - N88-BASICで使用されたソフトウェアLFOを搭載
      - OPL
        - OPL/OPLLの基本機能をカバー
        - オペレーターごとのハードウェアLFOを搭載
      - OPL3
        - OPL3の基本機能をカバー
        - 独自アルゴリズムの追加(2OPx2)
        - オペレーターごとのハードウェアLFOを搭載
      - OPM
        - OPMの基本機能(ハードウェアLFOも)をカバー
        - OPP のキースケール設定を追加
  - オリジナルのモダン風FM音源チャンネル・OPZX7S
    - ぼくのかんがえたさいきょうのFM音源オペレーター
      - OPZ/OPX/MA-7/OPSのいいとこどり＋独自機能を盛り込んだオペレーター
        - 謎な部分も多く(特にOPX)、**100%の再現は無理としても、再現できるところはできるだけ再現したい** という想いが詰まった、近似的な実装
    - 最大8オペレーター
      - OPX/OPZ/MA-7/OPSのアルゴリズムを選択可能
      - 独自アルゴリズムとして、1OP～8OPのアルゴリズムを選択可能
      - **アルゴリズムのグラフは画像からリアルタイム描画に切り替え**
    - **フィードバックはOP事に独立した値を設定可能**
      - 値は実数で、範囲は -8.0 ～ 8.0 (初期値: 0.0)
    - **アルゴリズムマトリックス**
      - 1OPから8OPまで、アルゴリズムを柔軟にカスタマイズ
      - モジュレーション・フィードバックの経路をチェックボックスでユーザーが指定
      - 従来の仕様ではあり得ないフィードバック設定も可能
    - オペレーターごとのアンプエンベロープは MA-7 準拠
      - 切り替えにより、実数での設定も可能
    - キースケールは MA-7/OPZ/OPS の設定をそれぞれ切り替え可能
    - MUL は MA-7/OPZ拡張版 を組み合わせたもの
      - MA-7 準拠のMUL選択
      - OPZ の MUL値(MulRatio) 設定を拡張、上限値を大幅に上昇
    - DT は OPZ の DT/DT2 に加えて、自由に値を設定できる DT3 を追加
    - 多彩な波形を選択可能
      - MA-7/OPZ の波形 + 独自波形
        - ※最初、Geminiが持ってきた MA-3 波形もどき(実際のMA-7波形とは似ても似つかないもの)も面白そうだったので、追加波形として盛り込み
      - 波形として、音声ファイルを使用可能(OPXの再現)
        - 再生開始位置と再生割合もサポート
      - 波形として、波形メモリ(`.wt` , `.wt2` ファイルに対応、MA-7の再現)
      - **ロードしたファイルの波形をプレビュー可能**
    - 強力なLFO
      - AM/PMで独立した周波数・シンクロ設定
      - 幅広いD/S設定値
      - CH単位・オペレータ単位のそれぞれで設定可能
      - **オリジナル波形追加**
    - OPNAのハードウェアSSGエンベロープを利用可能
    - ソフトウェア機能として、オペレーターごとに各種エンベロープを搭載

  - 以下の4エンベロープ(ソフトウェアエンベロープ的扱い)を追加
    - 6タップSSGソフトウェアエンベロープ(SSG SW ENV)
      - FMP7 の 6タップSSGソフトウェアエンベロープをベースに改良して搭載
      - R1～R6、STL、L1～L6のパラメータ、R6,L6はリリースパラメータという点はFMP7と同じ
        - レートは0.0秒～10.0秒まで設定可能
        - レベルは0.0～1.0まで設定可能
      - 指定タップ間でのループ対応(ループ回数の指定可能)
        - ループ回数は200まで
        - 0にすると無限ループ
    - **SSGハードウェアアンプエンベロープ**
      - OPNA/OPZX7S/SSGに搭載されていたSSH HW ENVを大幅拡張
      - オリジナル波形追加
      - 範囲のMIN/MAXを指定可能
      - 波形プレビュー
    - 11タップSSGソフトウェアエンベロープ(SSG SW ENV11)
      - SSG SW ENV11 のタップ数を 11 まで拡張
        - レートは0.0秒～10.0秒まで設定可能
        - レベルは0.0～1.0まで設定可能
      - リリースパラメータを R11/L11 に変更
      - ループ機能は SSG SW ENV を継承
    - 3タップピッチエンベロープ(Pitch Env)
      - 3タップのピッチ(音の高さ)を変更するエンベロープ
      - レートはAR/DR/RRの3種類
        - 0.0秒～10.0秒まで設定可能
      - レベルはSTL/ATL/SSL/RLLの4種類
        - それぞれ、-4800セント～4800セントまで設定可能
    - 11タップピッチエンベロープ(SSG SW PENV11)
      - SSG SW ENV11のピッチエンベロープ版
      - ピッチの変化がより豊かに
        - レート・レベルは従来のピッチエンベロープと同じ
          - レートは0.0秒～10.0秒まで設定可能
          - レベルは-4800セント～4800セントまで設定可能

        - 8波形からリアルタイムに切り替え可能

## 9. インストール方法

- アーカイブファイルを展開すると、「構成」で示したファイルが作成されますので、以下のように操作します。

### 9-1. 2686V.vst3 / 2686VLight.vst3 / 26V.vst3 / 86V.vst3 / OPZX7S.vst3 / 2686VFX.vst3

- VST3フォルダ内にコピーします
  - VST3フォルダは大体以下の場所にあります
    - `C:\Program Files\Common Files\VST3`
  - **VST3フォルダ内へのコピーには管理者権限が必要です**

### 9-2. Assetsフォルダ

- `Assets`フォルダの直下に `2686V` フォルダがありますので、このファイルを**ドキュメントフォルダの直下**に**必ず**コピーしてください

### 9-3. 2686V.exe / 2686VLight.exe / 26V.exe / 86V.exe / OPZX7S.exe / 2686VFX.exe

- 適当なフォルダにコピーしてください。
