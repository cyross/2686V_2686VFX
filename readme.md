# レトロ音源風VST「2686V」v3.0.0 README

(C)2026 CYROSS

## 1. はじめに

「2686V」(以降、合わせて「本ソフト」と表記します)は、レトロ音源(FM/SSG/ADPCM等)風の音を出すプラグイン「2686V」「2686V Light」「2686V Origin」「OPZX7S」を提供します。

## 2. 目的

DAW上で、「PC-9801-26」と「PC-9801-86」を再現したような曲を作りたかったけど眼鏡にかなうものがなかったので、プラグインを作ろう…としたはずだったが…

## 3. 概要

- 2686V:
  - ぼくのかんがえたさいきょうのレトロ音源VSTプラグイン
  - 当方の技術スタックでは100%再現するのは不可能だったため、不可能なら不可能なりに色々な音源風に聞こえるプラグインを作成した
  - また、目的は「曲を作ること」だったため、開発当初はコードはほぼ `Gemini3` による実装で執り行った。
- 2686V Light:
  - 2686Vの軽量版
  - 2686Vからカーブ編集モードを省いて負荷を下げたもの
- 2686V Origin:
  - 2686V Lightの構成を「PC-9801-86」に近づけたもの
    - チャンネルはOPNA、SSG、RHYTHM、PCMのみ
    - 「ADPCM」のチャンネル名を「PCM」に変更、初期の音質を「4-bit PCM」に変更
    - RHYTHMチャンネルを6に変更
- OPZX7S:
  - モダンFM音源オペレータ的位置のプラグイン
  - 2686VからOPZX7Sチャンネルとカーブ編集モードを抜き出した形で負荷を下げたもの
  - 標準でカーブ編集モードを適応(従来の線形モードをオミット)

## 4. 特徴

- 多彩なレトロゲーム音源(チャンネル)を楽しめる
  - ※各音源は「チャンネル」という単位で区分け
  - 各チャンネルはタブで切り替え可能
  - **ただし、1プラグインで同時に再生できるのは 1 チャンネルのみ**
    - DAWのトラックのほうが柔軟に構成を変えられるという思想で設計
- 多数のハードウェア由来FM音源チャンネル(OPNA/OPN/OPL/OPL3/OPM)
  - 多数のFM音源オペレーターの再現に、設計思想を崩さない(たぶん)程度の拡張を追加
  - OPL/OPL3/OPM/OPNA
    - それぞれに搭載されていたハードウェアLFOを搭載
  - OPN/OPNA
    - N88-BASICで使用されたソフトウェアLFOを搭載
  - OPM
    - OPP のキースケール設定を追加
  - OPL3
    - 独自アルゴリズムの追加(2OPx2)
  - オペレータ標準搭載のアンプエンベロープのオプション機能
    - KOR(Keep On Release)
      - リリース後、指定時間まで音量が減衰しない
      - SSGソフトウェアエンベロープを優先するときに使用
    - XOF
      - RRを無視し、無期限で減衰しない
      - SSGソフトウェアエンベロープを優先するときに使用
    - Bypass
      - アンプエンベロープをバイパス
      - SSGソフトウェアエンベロープを優先するときに使用
  - ハードウェア機能として、オペレーターごとに効果音モード、オペレーターマスクを搭載
  - ソフトウェア機能として、オペレーターごとにピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
  - 特殊機能として、オペレーターごとにMML入力機能を搭載
- オリジナルのモダン風FM音源チャンネル・OPZX7S
  - ぼくのかんがえたさいきょうのFM音源オペレーター
    - OPZ/OPX/MA-7/OPSのいいとこどり＋独自機能を盛り込んだオペレーター
      - 謎な部分も多く(特にOPX)、**100%の再現は無理としても、再現できるところはできるだけ再現したい** という想いが詰まった、近似的な実装
  - 最大8オペレーター
    - OPX/OPZ/MA-7/OPSのアルゴリズムを選択可能
    - 独自アルゴリズムとして、1OP～8OPのアルゴリズムを選択可能
  - アルゴリズムマトリックス
    - 1OPから8OPまで、アルゴリズムを柔軟にカスタマイズ
    - モジュレーション・フィードバックの経路をチェックボックスでユーザーが指定
    - 従来の仕様ではあり得ないフィードバック設定も可能
    - ※フィードバック値は1種類のみ設定可能
  - アンプエンベロープは MA-7 準拠
    - ただし、切り替えにより、実数での設定も可能
  - キースケールは MA-7/OPZ/OPS の設定をそれぞれ切り替え可能
  - MUL は MA-7/OPZ拡張版 を組み合わせたもの
    - MA-7 準拠のMUL選択
    - OPZ の MUL値(MulRatio) 設定を拡張、上限値を大幅に上昇
  - DT は OPZ の DT/DT2 に加えて、自由に値を設定できる DT3 を追加
  - 多彩な波形を選択可能
    - MA-7/OPZ の波形 + 独自波形
      - ※最初、Geminiが持ってきた MA-3 波形もどき(実際のMA-7波形とは似ても似つかないもの)も面白そうだったので、追加波形として盛り込み
    - 波形として、音声ファイルを使用可能(OPXの再現)
      - 再生開始位置と再生割合もサポート
    - 波形として、波形メモリ(`.wt` , `.wt2` ファイルに対応、MA-7の再現)
  - 強力なLFO
    - AM/PMで独立した周波数・シンクロ設定
    - 幅広いD/S設定値
    - CH単位・オペレータ単位のそれぞれで設定可能
  - OPNAのハードウェアSSGエンベロープを利用可能
  - ソフトウェア機能として、オペレーターごとに効果音モード、オペレーターマスク、ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
    - ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)については後述
  - 特殊機能として、オペレーターごとにMML入力機能を搭載
- SSG(PSG)チャンネル
  - 完全再現ではなく、PSGの機能も盛り込んだ強化版
  - 矩形波と三角波を用意
  - パルス波は、SSGだけではなくファミコンやKONAMI VRC VIのデューティ比に対応
  - デューティ比の任意設定も可能
  - 位相逆転可能
  - ファミコン風の波形に変更するスイッチを搭載
  - 三角波は、ピーク位置の調整が可能
    - これにより、鋸波も実現
  - 独自LFO搭載
  - 効果音モード、OPZX7SのLFO、OPZX7SのMUL/DT、ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
    - ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)については後述
- 波形メモリチャンネル(WT/WT2)
  - プリセット波形メモリとカスタム波形メモリを用意
  - 実数で値を設定する WT と、段階で指定する WT2 を搭載
  - カスタム波形メモリは、32/64/128/256サンプルに対応
  - 各種補助ボタンを準備
  - キー同時押しによる、値のアライメント対応
    - 0.01,0.05,0.1,16段階,32段階,64段階
  - 波形メモリのインポート・エクスポート
    - `.wt` , `.wt2` ファイル(テキストファイル)使用
  - 独自モジュレーション搭載
  - 効果音モード、OPZX7SのLFO、OPZX7SのMUL/DT、オペレーターマスク、ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
    - ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)については後述
- リズム音源チャンネル(RHYTHM)
  - ビットクラッシャー付きのドラムマシン
    - 多数のビットレートとサンプリングレートを選択可能
      - 4bit-ADPCM対応
      - 1bit-DPCM対応
    - 再生開始位置と再生割合、ループポイントをサポート
  - 8個(Originでは6個)のパッドが付属
    - YM-2608Bでは6個だったが、8個に拡張
      - 2686V Origin では 86音源に準拠するため、6個のまま
    - 各パッドに音声ファイルと割り当て対応
    - MIDIキー割り当てのカスタム対応
  - 各パッドに効果音モード、OPZX7SのLFO、OPZX7SのMUL/DT、オペレーターマスク、ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
    - ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)については後述
- 音声ファイルチャンネル(ADPCM/PCM)
  - 1つの音声ファイルをサンプラーのように再生可能
    - 多数のビットレートとサンプリングレートを選択可能
      - 4bit-ADPCM対応
      - 1bit-DPCM対応
    - 再生開始位置と再生割合、ループポイントをサポート
  - 効果音モード、OPZX7SのLFO、OPZX7SのMUL/DT、オペレーターマスク、ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
    - ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)については後述
- BEEPチャンネル
  - ビープ音(固定デューティ比の矩形波)を再現
    - 効果音モードでは 2000Hz への変更ボタンを搭載
  - 効果音モード、OPZX7SのLFO、OPZX7SのMUL/DT、オペレーターマスク、ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)を搭載
    - ピッチエンベロープ(3タップ/11タップ)、SSGソフトウェアエンベロープ(6タップ/11タップ)については後述
- 各種追加エンベロープ
  - 以下の4エンベロープ(ソフトウェアエンベロープ的扱い)を追加
    - 6タップSSGソフトウェアエンベロープ(SSG SW ENV)
      - FMP7 の 6タップSSGソフトウェアエンベロープをベースに改良して搭載
      - R1～R6、STL、L1～L6のパラメータ、R6,L6はリリースパラメータという点はFMP7と同じ
        - レートは0.0秒～10.0秒まで設定可能
        - レベルは0.0～1.0まで設定可能
      - 指定タップ間でのループ対応(ループ回数の指定可能)
        - ループ回数は200まで
        - 0にすると無限ループ
    - 11タップSSGソフトウェアエンベロープ(SSG SW ENV11)
      - SSG SW ENV11 のタップ数を 11 まで拡張
        - レートは0.0秒～10.0秒まで設定可能
        - レベルは0.0～1.0まで設定可能
      - リリースパラメータを R11/L11 に変更
      - ループ機能は SSG SW ENV を継承
    - 3タップピッチエンベロープ(Pitch Env)
      - 3タップのピッチ(音の高さ)を変更するエンベロープ
      - レートはAR/DR/RRの3種類
        - 0.0秒～10.0秒まで設定可能
      - レベルはSTL/ATL/SSL/RLLの4種類
        - それぞれ、-4800セント～4800セントまで設定可能
    - 11タップピッチエンベロープ(SSG SW PENV11)
      - SSG SW ENV11のピッチエンベロープ版
      - ピッチの変化がより豊かに
        - レート・レベルは従来のピッチエンベロープと同じ
          - レートは0.0秒～10.0秒まで設定可能
          - レベルは-4800セント～4800セントまで設定可能
  - すべてのチャンネル・オペレーター・リズムパッドに適応
- 独立エフェクト対応
  - 多数のモダンなエフェクトを標準搭載
    - フィルター
    - 3バンドEQ
    - ビブラート
    - トレモロ
    - リバーブ
    - ディレイ
    - モダンビットクラッシャー
    - SFCエコー
      - SPC-700相当の8タップFIRフィルタ
  - バイパス対応
- 拡張設定・カーブ編集モード(2686V/OPZX7S)
  - レジスタの値の変化・エンベロープのレベルの変化を柔軟に変更するモード
    - 従来のモードはスイッチで切り替え
    - OPZX7では標準でカーブ編集モード対応(従来モードへの変更不可)
    - 2686V Light と 2686V Origin はカーブ編集モード非搭載
      - 負荷軽減のため
  - 従来の線形変化モードを拡張
    - 30種類以上の変化ロジック
      - 通過ポイントによる変更割合の切り分けや指数カーブ・対数カーブ・スプライン曲線(1点・2点)による変化に対応
- 値の範囲を確認可能
  - スライドバーのボタンをホバーすると範囲を表示
  - 設定画面でにON/OFF切り替え可能
- ユニゾン・ハーモニーモード
  - 最大8音対応
  - デチューン・空間によるハーモニー対応
- 和音演奏可能
  - モノフォニックモードとの切り替え
  - 最大同時10ボイス対応
    - ユニゾン・ハーモニーをかけ合わせると最大80ボイス
  - ヘッドルーム確保ゲインの変更可能
- もちろん、オートメーション可能
- MIDIキーボードのピッチベント・モジュレーション機能対応
- 3種類の画面表示
  - フル表示
  - ミニプレイヤー表示
  - ミニマム表示
- プリセットの保存・読み込み可能
  - 読み込まれている音声・波形ファイルは相対ディレクトリで保存
  - プリセットの簡易検索機能搭載
- 各チャンネルのパラメータをインポート・エクスポート可能
  - テキストファイルによる入出力
  - エンベロープ単位での入出力も可能
  - カーブ編集のパラメータの入出力可能
- 壁紙の設定が可能
  - 複数の表示モードを用意

## 9. インストール方法

- アーカイブファイルを展開すると、「構成」で示したファイルが作成されますので、以下のように操作します。

### 9-1. 2686V.vst3 / 2686VLight.vst3 / 2686VOrigin.vst3 / OPZX7S.vst3

- VST3フォルダ内にコピーします
  - VST3フォルダは大体以下の場所にあります
    - `C:\Program Files\Common Files\VST3`
  - **VST3フォルダ内へのコピーには管理者権限が必要です**

### 9-2. Assetsフォルダ

- `Assets`フォルダの直下に `2686V` フォルダがありますので、このファイルを**ドキュメントフォルダの直下**に**必ず**コピーしてください

### 9-3. 2686V.exe / 2686VLight.exe / 2686VOrigin.exe / OPZX7S.exe

- 適当なフォルダにコピーしてください。

## 10. アンインストール方法

- VST3フォルダ内にある2686V.vst3を削除すればアンインストールは完了です。
