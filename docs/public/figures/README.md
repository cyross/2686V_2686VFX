# 図の置き場所

マニュアルの一覧表から見に行くフォルダです。

ファイル名は**値を 2 桁にしたもの**です。値 0 なら 00.png、値 12 なら 12.png、
値 100 なら 100.png になります。

置いていない番号は、表の図の列が空欄になります。全部そろえなくても
構いません。

| --- | --- |
| alg/opna | OPNA のアルゴリズム (0-7) |
| alg/opn | OPN のアルゴリズム (0-7) |
| alg/opl | OPL のアルゴリズム (0-1) |
| alg/opl3 | OPL3 のアルゴリズム (0-7) |
| alg/opm | OPM のアルゴリズム (0-7) |
| alg/opzx7 | OPZX7S のアルゴリズム (0-129) |

| wave/opzx7-lfo | OPZX7S の LFO 波形 (0-12) |
| wave/opna-hw-lfo | OPNA のハードウェア LFO (0-5) |
| wave/opna-n88-lfo | OPNA の N88 LFO (0-3) |
| wave/opm-hw-lfo | OPM のハードウェア LFO (0-4) |
