WT は**波形メモリ**のチャンネルです。ファミコンのディスクシステムや PC エンジン、ワンダースワンなどのほか、ナムコのアーケードゲーム(C30)、コナミのMSX用カートリッジ(SCC) 等で使われていた方式で、**ひと山ぶんの波形を自分で描いて**それを繰り返し鳴らします。

FM のように変調で音を作るのではなく、**波形の形がそのまま音色になります。**
思ったとおりの倍音を並べられる反面、動きのある音は別のしくみ（エンベロープや
変調）で作ることになります。

## 表記について

| 表記 | 意味 |
| --- | --- |
| **実機** | 実機にある機能。実機の仕様どおりに動きます |
| **独自** | 実機に無い、このプラグイン独自の拡張 |

## WT と WT2 の違い

同じ波形メモリでも、**値の決め方**が違います。

| | WT | WT2 |
| --- | --- | --- |
| 値の持ち方 | **実数**（-1.0〜1.0） | **段階**（整数の目盛り） |
| 向いていること | なめらかな波形 | 実機の解像度に合わせた波形 |
| ファイル | `.wt` | `.wt2` |

実機はどれも段階で値を持っていたので、**当時の音に寄せたいときは WT2**、
自由に描きたいときは WT、という使い分けになります。

## FORM — 波形の設定

### SIZE — サンプル数

ひと山を何点で表すかを決めます。

| 値 | サンプル数 |
| --- | --- |
| 0 | 32 |
| 1 | 64 |
| 2 | 128 |
| 3 | 256 |

**点が多いほど細かい波形**を描けますが、当時の実機は 32 点前後が普通でした。
実機らしさを狙うなら少なめにします。


| つまみ | 内容 | オートメーション |
| --- | --- | --- |
| **SIZE** | 1 周期のサンプル数。32 / 64 / 128 / 256 | [`WT_SIZE`](/2686V_2686VFX/reference/automation/wt/#wt-size) |
| **STEP** | 描くときの値の刻み | [`WT_STEPS`](/2686V_2686VFX/reference/automation/wt/#wt-steps) |
| **FORM** | 組み込みの波形か、自分で描いたものか | [`WT_WAVE`](/2686V_2686VFX/reference/automation/wt/#wt-wave) |

### 波形の描き方

グラフを直接ドラッグして描きます。**修飾キーを押しながら**にすると値が刻みに
そろいます。

| キー | 刻み |
| --- | --- |
| **Shift** + ドラッグ | 0.01 |
| **Ctrl** + ドラッグ | 0.05 |
| **Alt** + ドラッグ | 0.1 |

何も押さなければ刻みなしで自由に描けます。細かく描いたあと、修飾キーで形を
整えるという使い方ができます。

### 補助ボタン

| ボタン | はたらき |
| --- | --- |
| `-> 1.0` / `-> 0.0` / `-> -1.0` | すべての点をその値にそろえる |
| **STEP** | 段階の数を指定して丸める |
| **Interpolate** | 点と点のあいだをなめらかにつなぐ（初期は入） |

**Interpolate** を切ると点が階段状のまま鳴り、より粗い音になります。実機の
質感に寄せたいときに使います。

### WAVE FILE — ファイルの読み書き

`.wt` ファイルとして読み書きできます。テキストファイルなので、他の道具で
作ったものを持ち込めます。

:::note
`.wt` / `.wt2` は **3.0.0 でも形式が変わっていません。** 以前作ったファイルを
そのまま読めます。
:::

## MOD — 波形メモリのピッチ変調（実機・独自）

波形メモリ系の実機が持っていた**音程の変調**です。ここが WT の要になります。

| 項目 | 内容 | 範囲 |
| --- | --- | --- |
| **Enable** | 変調を使うか | 入 / 切 |
| **DEPTH** | 掛かり具合 | 0.1〜1.0（初期 0.2） |
| **SPEED** | 速さ。**搬送波の周波数に対する比** | 0.1〜10.0（初期 1.0） |
| **SHAPE** | 変調のしかた | 下表 |

### SHAPE で選べる方式

| 値 | 方式 | 備考 |
| --- | --- | --- |
| 0 | 正弦波 | FDS の簡易版 |
| 1〜4 | **FDS (2C33)** の 32 ステップ（三角 / のこぎり / リセット / 台形） | |
| 5〜6 | **WonderSwan ch3** のスイープ（上昇 / 下降） | ワンダースワンで使われていた方式 |
| 7 | **HuC6280** — 波形メモリそのものを変調に使う | PCエンジンで使われていた方式 |
| 8 | **FdsUser** — FDS のテーブルをその場で編集 | |

**HuC6280 モード**では変調用の波形を 8 枚まで持て、リアルタイムに切り替え
られます。**FdsUser** では 32 エントリのテーブルを実機と同じ 3bit の値で
直接編集できます。

SPEED が搬送波との比なのは実機どおりです。**整数比にすると倍音として噛み合い**、
半端な比にするとうなりや不安定な揺れになります。

## 共通の区分

以下は音源に依らない部分です。それぞれの詳しい説明は
[共通の区分](/2686V_2686VFX/chips/common/) にまとめてあります。

| 区分 | 内容 |
| --- | --- |
| [**QUALITY**](/2686V_2686VFX/chips/common/#quality) | ビット数とサンプリング周波数を落として質感を作る |
| [**ENVELOPE**](/2686V_2686VFX/chips/common/#envelope) | [AMP ENV](/2686V_2686VFX/chips/common/#amp-env) / [SSG HW AMP ENV](/2686V_2686VFX/chips/common/#ssg-hw-amp-env) / [SSG SW AMP ENV](/2686V_2686VFX/chips/common/#ssg-sw-amp-env) / [SSG SW AMP ENV\[11\]](/2686V_2686VFX/chips/common/#ssg-sw-amp-env11) / [PITCH ENV](/2686V_2686VFX/chips/common/#pitch-env) / [SSG HW PITCH ENV](/2686V_2686VFX/chips/common/#ssg-hw-pitch-env) / [SSG SW PITCH ENV\[11\]](/2686V_2686VFX/chips/common/#ssg-sw-pitch-env11) |
| [**LFO**](/2686V_2686VFX/chips/common/#lfo) | 音量・音程を周期的に揺らす（OPZX7S のものを使用） |
| [**MUL/DET**](/2686V_2686VFX/chips/common/#muldet) | 音程をずらす |
| [**UNISON/HARMONY**](/2686V_2686VFX/chips/common/#unisonharmony) | 同じ音を重ねて厚くする |
| [**UTILITY**](/2686V_2686VFX/chips/common/#utility) | パラメータの読み書き |

QUALITYの詳細は、[リファレンス](../reference/lists-quality.md) をご参照ください。
