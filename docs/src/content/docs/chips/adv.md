**ADV** タブは、値が時間とともに**どう変わっていくか**を決めるところです。

実機のエンベロープは、レート（速さ）を決めると変化のしかたも決まっていました。
一直線に動くか、実機の癖に沿った動きをするかのどちらかです。カーブ編集は、
**その途中の形を自分で描けるようにしたもの**です。

:::note[使えるプラグイン]
カーブ編集は **2686V** と **OPZX7S** にあります。2686VLight と 86V は負荷を
下げるために外してあります。

**OPZX7S プラグインではカーブ編集が標準**で、従来の線形モードには戻せません。
:::

## 何に掛けられるか

「どこの」「何の」値を、「どう」変えるかの 3 つを決めます。

### Position — どこの

| 値 | 対象 |
| --- | --- |
| **Common** | チャンネル全体 |
| **Op1 〜 Op8** | オペレータごと |

### Target — 何の

| 対象 | 変えられる値 |
| --- | --- |
| **RegValue** | AR / DR(D1R) / SL(D1L) / RR / SR(D2R) / TL |
| **AmpEnv** | AR / DR / RR / SR |
| **PitchEnv** | AR / DR / RR |
| **SsgSwEnv** | R1〜R6 と LoopTo |
| **SsgSwEnv11** | R1〜R11 と LoopTo |
| **SsgSwPEnv11** | R1〜R11 と LoopTo |

レジスタの値そのものにも、各エンベロープのレートにも掛けられます。

## Logic — どう変えるか

**31 種類**から選びます。大きく分けると次のとおりです。

### 単独のもの

| ロジック | 動き |
| --- | --- |
| **線形** | 一直線。従来の動き |
| **円弧（指数的）** | はじめゆっくり、あとで急に |
| **円弧（対数的）** | はじめ急に、あとでゆっくり |
| **指数関数** | 加速していく |
| **対数関数** | 減速していく |
| **1点スプライン** | 通過点を 1 つ置いて曲げる |
| **2点スプライン** | 通過点を 2 つ置いて曲げる |

### 組み合わせたもの

**通過ポイントで区切って、区間ごとに違う動き**をさせられます。

| 形 | 例 |
| --- | --- |
| 2 区間 | `線形 + 指数関数` / `1点スプライン + 線形` |
| 3 区間 | `線形 + 対数関数 + 線形` / `線形 + 線形 + 線形` |
| 同じものの繰り返し | `2点スプライン + 2点スプライン + 2点スプライン` |

たとえば `線形 + 円弧(対数的) + 線形` なら、**まっすぐ落ちる → ゆるくカーブ
する → またまっすぐ落ちる**、という動きになります。

## 通過ポイントと制御点

区間の切れ目や曲がり具合は、画面の値で決めます。

| 記号 | 意味 |
| --- | --- |
| **PX** / **PY**（`P1X`〜`P2Y`） | 通過ポイントの位置 |
| **CX** / **CY**（`C1X`〜`C6Y`） | 曲がり具合を決める制御点 |

X が時間の方向、Y が値の方向です。スプラインを選ぶと制御点が増えます。

## 使いどころ

:::tip[音が伸びる感じを作る]
AMP ENV の DR に `対数関数` を掛けると、**はじめに素早く落ちて、あとはゆっくり
残る**動きになります。実機の一直線な減衰より、生楽器に近い伸び方になります。
:::

:::tip[当時らしさを保ちたいとき]
逆に、実機の音を狙うなら **`線形` のまま**にしておきます。カーブを掛けると、
実機には出せなかった動きになるためです。
:::

## 負荷について

カーブ編集は 1 サンプルごとに計算するので、そのぶん負荷が上がります。**使わ
ないなら 2686VLight を選んだほうが軽く動きます。**

プラグインの違いは
[プラグインの選び方](/2686V_2686VFX/plugins/compare/) を参照してください。

## ファイル

カーブのパラメータは、ほかのパラメータと同じように読み書きできます。形式は
[ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を参照してください。
