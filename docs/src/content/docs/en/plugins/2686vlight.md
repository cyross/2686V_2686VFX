## Curve editing (ADV)

**Not included.** It was left out to keep the load down.

Pick 2686V or OPZX7S when you want curve editing.

## When to reach for it

- When you are not going to use curve editing
- When there are many tracks and you want to keep the load down

## Files

| What | Extension |
| --- | --- |
| Preset | `.2686vl.json` |
| Parameter files | shared with the other plugins |

Every plugin uses its own preset extension, so you can keep one
`Presets` folder for all of them and each plugin still lists only its own.
Parameter files, on the other hand, **can be read across plugins**.

For where the files live, see
[File formats and locations](/2686V_2686VFX/en/files/format/).

:::note
Parameter files and presets have the same shape as 2686V's. Only the curve settings are skipped.
:::
