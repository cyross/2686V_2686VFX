This chapter collects tutorials that teach the controls while you build sounds.
What happens on screen is shown in videos and animated pictures.

What each control means and its range are covered in chapters such as
[Sound chips](/2686V_2686VFX/en/chips/common/). The tutorials follow
"what to touch, in what order, and how it sounds".

:::note
Tutorials will be added over time.
:::
