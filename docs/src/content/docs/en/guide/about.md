2686V recreates the sound chips found in home computers and game consoles of
the 1980s and 90s. It runs as a VST3 plugin and as a standalone application.

## Four plugins

The four builds differ only in which chips they carry. The shared screens and
the way you work with them are identical, so most of this manual applies to all
of them. The differences are listed in
[Choosing a plugin](/2686V_2686VFX/en/plugins/compare/).

| Plugin | What it is |
| --- | --- |
| **2686V** | The full build, with every chip |
| **2686VLight** | 2686V without curve editing |
| **86V** | Matched to the PC-9801-86 sound board |
| **OPZX7S** | Focused on the OPZX7 chip. Curve editing is standard |

## Requirements

- Windows
- A DAW that hosts VST3, or the standalone application

## A note on accuracy

Where a feature exists on the real hardware, it follows the hardware's
specification. Anything added beyond that is marked as an original extension in
this manual, so you can leave those controls alone when you want the authentic
sound.
