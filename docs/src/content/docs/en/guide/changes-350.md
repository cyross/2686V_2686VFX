This page covers changes from 3.4.0 to 3.5.0. **Your files remain compatible.**
Presets and parameter files made in 3.4.0 or earlier can be loaded without changes.

## Language selection support

**You can now switch the display language between Japanese and English.**

- A language selection dropdown has been added to the top of the **SETTINGS** tab.
- The options are always displayed in their respective native scripts ("日本語" and "English"), so you can easily revert the setting even if you accidentally choose a language you cannot read.
- By default, the plugin automatically detects your OS language, falling back to English for any language other than Japanese.
- Switching the language rebuilds the screen immediately on the fly.
- This feature is available across all 12 plugins in the family.

## User's manual link on the ABOUT tab

**A button to open this user's manual (website) has been added to the ABOUT tab.**

- It opens the manual in your selected language: the Japanese version when Japanese is selected, and the English version (/en/) when English is selected.

## Other adjustments

- Expanded the width of the "Format" label on the **PRESET** tab slightly to accommodate the English text.
- Removed the parenthesized "(Oscilloscope)" from the wave preview heading in the English layout to ensure the "Waveform preview" text fits within the frame.
