**COLORS** タブで色を選ぶときに使える名前の一覧です。使い方は
[色の指定](/2686V_2686VFX/reference/colors/) を参照してください。

## このプラグインで付けた名前

画面の基調に使っている色です。**見本は初期値**のもので、COLORS タブで
変えたあとの色ではありません。

| 見本 | 名前 | 初期値 | 使いどころ |
| :---: | --- | --- | --- |
| <span style="display:inline-block;width:44px;height:18px;border-radius:3px;border:1px solid var(--sl-color-gray-4);background:#F5F5F5;vertical-align:middle;"></span> | `OffWhite` | `#F5F5F5` | 明るいほうの基調 |
| <span style="display:inline-block;width:44px;height:18px;border-radius:3px;border:1px solid var(--sl-color-gray-4);background:#39423F;vertical-align:middle;"></span> | `OffBlack` | `#39423F` | 暗いほうの基調 |
| <span style="display:inline-block;width:44px;height:18px;border-radius:3px;border:1px solid var(--sl-color-gray-4);background:rgba(128,128,128,0.30);vertical-align:middle;"></span> | `BorderGray` | `#808080（透明度 30%）` | 枠線 |
| <span style="display:inline-block;width:44px;height:18px;border-radius:3px;border:1px solid var(--sl-color-gray-4);background:rgba(128,128,128,0.50);vertical-align:middle;"></span> | `ShadowGray` | `#808080（透明度 50%）` | 影 |
| <span style="display:inline-block;width:44px;height:18px;border-radius:3px;border:1px solid var(--sl-color-gray-4);background:#CCCCFF;vertical-align:middle;"></span> | `SliderBarBlue` | `#CCCCFF` | スライダーのバー |
| <span style="display:inline-block;width:44px;height:18px;border-radius:3px;border:1px solid var(--sl-color-gray-4);background:#CCCCFF;vertical-align:middle;"></span> | `DialogOkBackBlue` | `#CCCCFF` | ダイアログの決定ボタン |

:::
