DAW のオートメーションから動かせるパラメータの一覧です。全部で **7296 件**
あります。チャンネルごとにページを分けてあります。

一覧は、プラグインが実際に登録しているものをそのまま書き出して作っています。
手で書き写してはいないので、抜けや食い違いは起きません。

## 表の見方

| 列 | 中身 |
| --- | --- |
| **オートメーション名** | DAW のオートメーション一覧に出る名前 |
| **ID** | ファイルの中で使われる名前。プリセットを直接編集するときに使う |
| **型** | Int（整数）/ Float（小数）/ Bool（真偽）/ Choice（選択） |
| **範囲** | 取りうる値 |
| **初期値** | 初期状態の値 |

## 真偽（Bool）の扱い

オートメーションの値は 0.0〜1.0 で送られます。真偽のパラメータは次のように
解釈されます。

- **0.00 〜 0.49** … False
- **0.50 〜 1.00** … True

初期値も同じで、**False なら 0.0、True なら 1.0** を送れば同じ状態になります。

## カーブ（ADV）について

:::caution
**カーブの設定はオートメーションできません。**

カーブは 9 (Position) × 6 (Target) × 16 (Param) = 864 枠あり、1 枠あたり 18 個
のパラメータを持ちます。すべて登録すると 15,000 個以上増え、DAW のオート
メーション一覧が実用に耐えなくなるため、通常のパラメータとしては登録して
いません。

カーブの内容はプリセットへ保存されるので、プリセットを切り替えることで
まとめて差し替えられます。
:::
