**COLORS** タブでは、画面に使う色をひとつずつ変えられます。色の決め方は
4 通りあります。

| 決め方 | 内容 |
| --- | --- |
| RGB | 赤・緑・青の値で指定 |
| HSV | 色相・彩度・明度で指定 |
| 色名 | 名前の一覧から選ぶ |
| パレット | 実機が出せる色の中から選ぶ |

どれで選んでも、結果は同じ 1 色です。**ボタンひとつで初期値へ戻せます。**

## 色名

名前の一覧は 2 つの出どころが混ざっています。

### このプラグインで付けた名前

画面の基調に使っている 8 色です。まとめて雰囲気を変えたいときの起点になります。

| 名前 | 使いどころ |
| --- | --- |
| `OffWhite` | 明るいほうの基調 |
| `OffBlack` | 暗いほうの基調 |
| `BorderGray` | 枠線 |
| `ShadowGray` | 影 |
| `SliderBarBlue` | スライダーのバー |
| `DialogOkBackBlue` | ダイアログの決定ボタン |
| `MikuPink` | カテゴリの開いている表記 |
| `MikuBlack` | カテゴリの閉じている表記 |

:::note
最後の 2 つは、初音ミクの髪留めとヘッドホンの色をなぞったものです。カテゴリ
見出しのランプに使っています。
:::

### JUCE の色名

`aliceblue` や `tomato` のような、広く使われている色名も選べます。数が多いので、
一覧から探すより名前で絞り込むほうが早いことが多いです。

同じ色に両方の名前が当たるときは、**このプラグインで付けた名前が優先**されます。

## パレット

当時の機種が**実際に出せた色**だけを並べたものです。その機種の見た目に寄せ
たいときに使います。

| 機種 | 色の作り |
| --- | --- |
| **PC-8801** | RGB 各 3bit |
| **PC エンジン** | RGB 各 3bit |
| **メガドライブ** | RGB 各 3bit（段が等間隔ではない） |
| **PC-9801** | RGB 各 4bit |
| **X68000** | RGB 各 5bit ＋ 輝度 1bit |

並び順は色数の少ないものからです。**メガドライブだけは段が等間隔ではない**
ので、同じ 3bit でも他の 2 機種と出る色が違います。実機がそういう作りだった
ためで、そのまま再現しています。

## 設定の残り方

変えた色はファイルへ保存され、次に開いたときも残ります。プリセットとは別
なので、**プリセットを読み込んでも色は変わりません。**

保存先は
[ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を参照してください。
