FM 音源チャンネルで選べる**組み込みのアルゴリズム**です。オペレータの
結線を決めます。

OPZX7S はアルゴリズムマトリックスで自由に組めるので、ここに並ぶのは
**出発点として用意してあるもの**です。

:::note[図の置き場所]
**図**の列は `docs/public/figures/` の下を見に行きます。節ごとに決まった
フォルダがあり、ファイル名は**値を 2 桁にしたもの**（`00.png` `01.png` …）です。
置いていないあいだは何も出ません。
:::
