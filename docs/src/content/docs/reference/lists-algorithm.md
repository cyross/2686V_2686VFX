FM 音源チャンネルで選べる**組み込みのアルゴリズム**です。

:::note[画面では図で出ます]
アルゴリズムは、画面ではオペレータの結線図として描かれます。ここに並べて
いるのは**番号と、元になった音源・オペレータ数**です。どういう結線かは、
画面で選んで図を見るのが確実です。
:::

OPZX7S はアルゴリズムマトリックスで自由に組めるので、ここに並ぶのは
**出発点として用意してあるもの**です。
