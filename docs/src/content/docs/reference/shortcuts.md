## どこでも使えるもの

| キー | はたらき |
| --- | --- |
| **Ctrl** + **Z** | 元に戻す |
| **Ctrl** + **Y** | やり直す |
| **Ctrl** + **Shift** + **Z** | やり直す（Mac の流儀） |
| **Ctrl** + **C** | 開いているチャンネルのパラメータを文字列としてコピー |
| **Ctrl** + **I** | 開いているタブのパラメータを初期値へ戻す |
| **Q** | MIDI の設定を初期状態へ戻す |

:::note
Mac では **Ctrl** の代わりに **Command** です。プラグイン側で自動的に振り分け
ています。
:::

## FM 音源のタブで

| キー | はたらき |
| --- | --- |
| **1**〜**8** | そのオペレータの MML 入力を開く |
| **Alt** + **1**〜**8** | そのオペレータのマスクを入り切りする |
| **Ctrl** + **1**〜**8** | TARGET をそのオペレータへ移す |

テンキーの数字でも同じです。オペレータの数はチャンネルによって違うので、
無いオペレータの番号を押しても何も起きません。

MML の書き方は [MML 入力](/2686V_2686VFX/reference/mml/) を参照してください。

## TARGET のあるタブで

OPNA / OPN / OPL / OPL3 / OPM / OPZX7 / RHYTHM / WT+ / ADPCM+ には、
読み書きや編集の相手を選ぶ **TARGET** があります。

| キー | はたらき |
| --- | --- |
| **Ctrl** + **←** | TARGET をひとつ戻す |
| **Ctrl** + **→** | TARGET をひとつ進める |
| **Ctrl** + **1**〜**8** | TARGET をその番号へ移す |

**端まで来たら反対の端へ回ります。** 4 本のオペレータなら 4 の次は 1 へ、
1 の手前は 4 へ戻ります。

**Ctrl** + **1**〜**8** が効くのは、相手が 8 つまでの区分です。波形メモリ
(WT+) と PCM (ADPCM+) は 32 本あって数字では届かないので、**←** と **→**
だけを受けます。

## 波形メモリ（WT）の編集で

波形を直接ドラッグして描くとき、**修飾キーを押しながら**にすると値が刻みに
そろいます。細かく描いたあと形を整えるのに使えます。

| キー | 刻み |
| --- | --- |
| **Shift** + ドラッグ | 0.01 |
| **Ctrl** + ドラッグ | 0.05 |
| **Alt** + ドラッグ | 0.1 |

何も押さずにドラッグすると、刻みなしで自由に描けます。

:::note
WT2 は値そのものが段階で決まっているので、修飾キーによる刻みはありません。
段の数は画面から選びます。
:::

## ダイアログで

| キー | はたらき |
| --- | --- |
| **Enter** | 決定 |
| **Esc** | 取り消し |

## タブ移動

画面の部品は **Tab** キーで順に移れます。移る順番は画面の並びに沿うように
決めてあります。
