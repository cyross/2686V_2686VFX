FM 音源のチャンネルには、オペレータごとに **MML** ボタンがあります。当時の
音源ドライバの書き方でパラメータをまとめて流し込めます。

スライダーをひとつずつ動かす代わりに、手元のメモや既存の曲データから値を
そのまま貼り付けられます。

## 書き方

**記号と数字の組**を、空白で区切って並べます。記号と数字のあいだのコロンは
あってもなくてもかまいません。

```text
AR:31 DR:5 SL:2 RR:7 TL:20 MUL:1 DT:-1
```

```text
AR31 DR5 SL2 RR7 TL20 MUL1 DT-1
```

どちらも同じ意味です。負の値はそのまま `-1` と書きます。

:::note
知らない記号は読み飛ばします。他のドライバの書き方が混ざっていても、分かる
ぶんだけ反映されます。
:::

## 使えるチャンネル

MML 入力は **FM 音源のチャンネルだけ**にあります。SSG や波形メモリ、リズム
にはありません。

## 記号の一覧

チャンネルによって受け付ける記号が違います。同じ意味で複数の書き方を受ける
ものもあります（当時のドライバによって綴りが違ったためです）。

### すべての FM チャンネルで使えるもの

| 記号 | 意味 |
| --- | --- |
| `AR` | アタックレート |
| `DR` | ディケイレート |
| `RR` | リリースレート |
| `SL` | サスティンレベル |
| `TL` / `O` / `OL` | トータルレベル（音量） |
| `MUL` / `ML` | 逓倍 |
| `MASK` | オペレータマスク |

### OPNA / OPN

| 記号 | 意味 |
| --- | --- |
| `SR` | サスティンレート |
| `DT` | デチューン |
| `KS` | キースケール |

### OPL / OPL3

| 記号 | 意味 |
| --- | --- |
| `KSL` / `KL` | キースケールレベル |
| `KSR` / `KR` | キースケールレート |
| `AM` | 振幅変調 |
| `PM` / `VIB` / `VB` | 位相変調（ビブラート） |
| `EGTYPE` / `ET` | エンベロープの型 |

### OPM / OPZX7

| 記号 | 意味 |
| --- | --- |
| `D1R` | 第 1 ディケイレート |
| `D1L` | 第 1 ディケイレベル |
| `D2R` | 第 2 ディケイレート |
| `DT1` / `DT` / `DTO` | デチューン 1 |
| `DT2` / `DTT` | デチューン 2 |
| `KS` | キースケール（OPM のみ） |

## 値の範囲

値は**当時のレジスタの数値**で書きます。画面のスライダーが実数で表示されて
いても、MML では整数のレジスタ値です。

| 記号 | 範囲 |
| --- | --- |
| `AR` / `DR` / `SR` / `D1R` / `D2R` | 0〜31 |
| `SL` / `RR` / `D1L` | 0〜15 |
| `TL` | 0〜127 |
| `MUL` | 0〜15 |
| `DT` | -3〜3 |

範囲を超えた値は、いちばん近いところへ丸められます。

## 使い方

1. FM 音源のタブを開きます
2. 値を入れたいオペレータの **MML** ボタンを押します
3. 入力欄へ書いて、決定します

:::tip[キーボードから]
オペレータ番号のキー（**1**〜**8**、テンキーも可）を押すと、そのオペレータの
MML 入力が開きます。**Alt** を押しながらだとマスクの入り切りになります。
:::
