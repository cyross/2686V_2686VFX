**QUALITY** は、音のビット数とサンプリング周波数を落として当時の質感を
作るところです。チャンネルによって選べるものが違います。

| 種類 | 使うチャンネル |
| --- | --- |
| **BIT / RATE** | FM・SSG・波形メモリ系 |
| **BIT / RATE / INTP** | ADPCM・RHYTHM（PCM 系） |

## BIT — ビット数（FM・SSG・波形メモリ系）

単純に段階の数を落とします。`Raw` は落としません。

**0〜11 の 12 種類**です。名前は付いておらず、画面では結線図として出ます。

## BIT — ビット数（PCM 系）

段階を落とすものに加えて、**実機の圧縮方式**が並びます。圧縮方式は単にビット数を落とすのとは歪み方が違います。

**0〜20 の 21 種類**です。名前は付いておらず、画面では結線図として出ます。

## RATE — サンプリング周波数

下げるほど粗くなります。FM 系と PCM 系で同じ並びです。

**0〜14 の 15 種類**です。名前は付いておらず、画面では結線図として出ます。

## INTP — 補間のしかた（PCM 系）

レートを落としたあと、読み戻すときの埋め方です。

**0〜6 の 7 種類**です。名前は付いておらず、画面では結線図として出ます。
