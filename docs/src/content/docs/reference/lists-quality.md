**QUALITY** は、音のビット数とサンプリング周波数を落として当時の質感を
作るところです。**何番を選ぶと何になるか**をここで確かめられます。

| 種類 | 使うチャンネル |
| --- | --- |
| **BIT / RATE / INTERP** | FM・SSG・波形メモリ系 |
| **BIT / RATE / INTERP** + ノイズリダクション | ADPCM・RHYTHM（PCM 系） |

INTERP は 3.6.0 から FM・SSG・波形メモリ系にも付きました。BIT の中身は
FM 系と PCM 系で違うので、それぞれ別の表に分けてあります。

## INTERP — 補間のしかた

レートを落としたあと、埋め戻すときのやり方です。PCM 系では読み込んだ音を読み戻す
ときに、FM・SSG・波形メモリ系では音源が作った波をホストのレートへ戻すときに
使います。

**7 種類**あります。

初期値はチャンネルで違い、**3.6.0 より前と同じ音になる側**から始まります。
FM 系と SSG は「線形補間 (Linear)」、波形メモリ系の WT と WT+ は
「ZOH (Zero-Order Hold)」です。実機の出力に近いのは ZOH で、階段のままのざらつきが
残ります。

WT2 だけは「線形補間 (Linear)」から始まります。WT2 の QUALITY は 3.6.0 より前は
音源へ届いておらず、線形補間で鳴っていたためです。

ガウス補完・B-スプライン補間・ラグランジュ補間は 1 つ先の点を使うため、その 3 つを
選んだときだけ音源 1 サンプル分だけ遅れます (55.5kHz で 18 マイクロ秒、2.21kHz で
0.45 ミリ秒)。

| ---: | --- | --- |
| 1 | 補完なし (Nearest) | |
| 2 | 線形補間 (Linear) | |
| 3 | ガウス補完 (Gaussian) | スーパーファミコンのSPC-700で採用されている補完アルゴリズム |
| 4 | ZOH (Zero-Order Hold) | |
| 5 | コサイン補間 (Cosine) | |
| 6 | B-スプライン補間 (B-Spline) | |
| 7 | ラグランジュ補間 (Lagrange) | |
