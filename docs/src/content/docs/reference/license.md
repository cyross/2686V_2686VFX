## 作った曲について

**このソフトで作った曲や効果音は、商用・非商用を問わず自由に使えます。**
使用料はかかりません。作った作品の著作権は、作った人のものです。

報告や表記は必要ありませんが、
[連絡](#連絡先)をいただけると作者が喜びます。

## ソフト本体

配布されるプラグイン（VST3）には **GPLv3** が適用されます。「JUCE」
フレームワークと「VST3 SDK」に結びついているため、そちらのライセンス
（GPLv3 / AGPLv3）を受け継ぎます。

リポジトリの**ソースコードそのものは MIT ライセンス**です。ただし組み立てた
バイナリは上記のとおり GPLv3 に従うので、配るときは GPLv3 の条件を満たす必要
があります。

### 禁止していること

- 作者を偽って再配布すること
- 作者の許諾なく商用製品として販売すること

GPLv3 の規定により、著作権表示を書き換えたり消したりすることは認められて
いません。

## 付属のプリセット・サンプル

| 種類 | 扱い |
| --- | --- |
| プリセット（`OPLL Roms` 以外） | **無断転載は禁止**。作品への利用・改変は自由 |
| サンプル音声 | **無断転載は禁止**。作品への利用・改変は自由 |
| `OPLL Roms` のプリセット | `CC BY-SA 4.0` の下で再配布・再利用が可能 |

### OPLL Roms について

`OPLL Roms` フォルダのプリセットは、Plogue の David 氏が公開している
[Copyright free OPLL(x) ROM patches](https://github.com/plgDavid/misc/wiki/Copyright-free-OPLL(x)-ROM-patches)
のパッチデータを参考にしています。

元のデータが `CC BY-SA` で公開されているため、これらのプリセットも同じ条件で
扱えます。

- [CC BY-SA 4.0 (English)](https://creativecommons.org/licenses/by-sa/4.0/deed.en)
- [CC BY-SA 4.0 (日本語)](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)
