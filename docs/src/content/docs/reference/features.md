## エンベロープ

すべてのチャンネル・オペレータ・リズムパッドで使えます。

| 名前 | 対象 | 内容 |
| --- | --- | --- |
| AMP ENV | 音量 | ADSR。KOR / XOF / バイパスの独自オプション付き |
| SSG HW AMP ENV | 音量 | 実機のハードウェアエンベロープ。独自波形と範囲指定を追加 |
| SSG SW ENV | 音量 | 6 タップ。ループ回数の指定可 (0 で無限) |
| SSG SW ENV11 | 音量 | 11 タップ |
| PITCH ENV | 音程 | 3 タップ。±4800 セント |
| SSG SW PENV11 | 音程 | 11 タップ。±4800 セント |
| WT PITCH MOD | 音程 | 波形メモリによる変調。FDS / WonderSwan / HuC6280 |

## 2686VFX の出力への変調

2686VFX だけの機能です。音源側のエンベロープや LFO を、出力そのものへ掛け
られます。MIDI の鍵盤で動きます。詳しくは
[2686VFX (エフェクト)](/2686V_2686VFX/plugins/fx-plugin/) を参照してください。

| 枠 | 動かすもの |
| --- | --- |
| AMP ENV / SSG HW AMP ENV / SSG SW AMP ENV[11] | 音量 |
| LFO | 音量 (AM) と音程 (PM) |
| PITCH ENV / SSG SW PITCH ENV[11] / WT PITCH MOD | 音程 |
| MUL・DET / UNISON・HARMONY | 音程を一定量ずらす |

## 画面とファイル

| 機能 | 内容 |
| --- | --- |
| 表示モード | フル / ミニプレイヤー / ミニマム |
| 壁紙 | 画像を敷ける。表示のしかたを選べる |
| COLORS | 色をひとつずつ変更。当時のパレットから選べる |

:::
