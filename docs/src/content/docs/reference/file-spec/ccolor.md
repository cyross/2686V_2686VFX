画面の色の設定です。ほかのファイルと違い、**オートメーションとは関係しません**。

| | |
| --- | --- |
| **拡張子** | `.ccolor.json` / `.ccolor.yaml` |
| **表記（format）** | `2686V color settings` |
| **版（version）** | `1` |
| **書き出し・読み込み** | COLORS の「書き出し」「読み込み」 |

## かたち

```json
{
  "format": "2686V color settings",
  "version": 1,
  "colors": {
    "Editor.defaultBg": "ff1a1206",
    "Group.TitleText": "ffffb000"
  }
}
```

ほかのパラメータファイルと違い、`values` では包まず `colors` を直に持ちます。

## 色の書き方

**`aarrggbb` の 8 桁**（16 進）です。先頭の 2 桁が不透明度で、`ff` で
不透明になります。

色の名前は [色名リスト](/2686V_2686VFX/reference/color-names/) にあります。

## 書き出されるもの

**初期値から変えた色だけ**が書き出されます。全部を書くと、あとから色を
足したときに古いファイルが「初期値のまま」を上書きしてしまい、新しい初期値
が反映されなくなるためです。

読み込むときは、**書かれていない色はいったん初期値へ戻ります**。書き出した
ときの見た目と、読み込んだ結果がそろうようにしてあります。知らない名前は
読み飛ばすので、色を減らした版で書いたファイルでも読めます。

置き場所は [ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を参照してください。
