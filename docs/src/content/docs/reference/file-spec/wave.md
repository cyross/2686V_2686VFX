波形メモリの中身です。**JSON ではなく、1 行 1 つの数字を並べたテキスト**
です。表計算やスクリプトから作りやすいようにしてあります。

## .wt — 実数で持つ

| 行 | 内容 |
| --- | --- |
| 1 行目 | サンプル数。`32` / `64` / `128` / `256` |
| 2 行目以降 | 値。`-1.0` 〜 `1.0` |

```plaintext
32
0.000000
0.195090
0.382683
…
```

値の数は 1 行目のサンプル数と同じにします。

## .wt2 — 段で持つ

| 行 | 内容 |
| --- | --- |
| 1 行目 | サンプル数。`32` / `64` / `128` / `256` |
| 2 行目 | 段数。`16` / `32` / `64` / `128` / `256` |
| 3 行目以降 | 値。`0` 〜 段数 − 1 の整数 |

```plaintext
32
16
8
10
12
…
```

中央は段数の半分（16 段なら `8`）です。**段の粗さそのものが持ち味**なので、
同じ形でも段数を変えると聞こえ方が変わります。

## 使うところ

- WT / WT2 チャンネルの WAVE FILE
- WT+ の枠（最大 32）
- OPZX7 のオペレータ（WS で `.wt` / `.wt2` を選んだとき）
- [WT PITCH MOD](/2686V_2686VFX/chips/common/#wt-pitch-mod) の変調波形

置き場所は [ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を参照してください。
