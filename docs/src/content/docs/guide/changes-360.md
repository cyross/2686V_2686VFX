3.5.0 から 3.6.0 までの変更をまとめます。**読み込めなくなるファイルはありません。**
3.5.0 までに作ったプリセットやパラメータファイルは、そのまま読めます。新しく
足した設定は、どれも初期値が「これまでと同じ動き」になっているので、開いた
だけで音が変わることもありません。

## 2686VFX: 変調を動かす鍵盤を選べるようにしました

**エンベロープや LFO を、どの鍵盤で動かすかを対象ごとに決められるように
しました。** たとえば C3 で AMP ENV、D3 で PITCH ENV、E3 で LFO の AM、と
分けておけば、鍵盤の押し分けで掛ける変調を切り替えられます。

エフェクターの枠の、ファイルの読み書きの上に **キーアサイン** を足しました。

| 選択 | ふるまい |
| --- | --- |
| **シングルキーアサイン**（初期） | これまでどおり。どの鍵盤でも全部が動く |
| **キーアサインのカスタマイズ** | 対象ごとに決めた鍵盤でだけ動く。下に鍵盤の一覧が出る |

カスタマイズで選べる対象は 13 項目です。鍵盤は C-2 (0) 〜 G8 (127) から選べ、
初期値はすべて **C3 (60)** です。

| 対象 | 割り当てた鍵盤でのふるまい |
| --- | --- |
| AMP ENV / SSG HW AMP ENV / WT AMP MOD / SSG SW AMP ENV[11] | 押すと始まり、離すと戻る（これまでと同じ） |
| PITCH ENV / SSG HW PITCH ENV / SSG SW PITCH ENV[11] / WT PITCH MOD | 押すと始まり、離すと戻る（これまでと同じ） |
| LFO AM / LFO PM | **押している間だけ**掛かる。押したときに頭から回る |
| MUL/DET | **押している間だけ**掛かる |
| UNISON/HARMONY | **押している間だけ**掛かる |
| ARPEGGIO | **押している間だけ**アルペジオになる。押したときに 1 声目から始まる |

- 同じ鍵盤を複数の対象へ割り当てられます。その鍵盤を押すと、まとめて動きます
- カスタマイズのときは、変調の枠の見出しの色で、いま動いているかが分かります。
  割り当てた鍵盤が押されていない枠は灰、押されている間はオフホワイトです。
  LFO の枠は AM / PM のどちらか、UNISON/HARMONY の枠は UNISON / ARPEGGIO の
  どちらかの鍵盤が押されていればオフホワイトになります。シングルキーアサインでは、
  これまでどおりすべてオフホワイトです
- 複数の鍵盤を押したときは、それぞれに割り当てた処理がすべて動きます
- 処理する順番はこれまでと同じです
- LFO・MUL/DET・UNISON/HARMONY は、シングルキーアサインではこれまでどおり
  鍵盤に関係なく掛かります。カスタマイズにしたときだけ「押している間だけ」
  になります
- 割り当ては FX のパラメータファイル（`.2fx`）へ保存されます。キーアサインを
  持たない古いファイルを読んだときは、いまの割り当てのまま変わりません
- オートメーションは `MOD_KEYASSIGN_MODE` と `MOD_KEY_*`（対象ごとに 1 つ）です

詳しくは [出力への変調](/2686V_2686VFX/fx/mod/#キーアサイン--変調を動かす鍵盤) を参照してください。

## 札が切れている区分の中のつまみを止めるようにしました

**Bypass や Enable の札が効いていない区分では、中のつまみが押せなくなり、
薄く表示されるようになりました。** 動かしても音が変わらないつまみに触れて
迷うことがなくなります。札そのものは、いつでも押せます。

| 区分 | 止まるもの |
| --- | --- |
| AMP ENV / PITCH ENV | Bypass が入っているあいだ、中のつまみすべて |
| SSG HW AMP ENV / SSG HW PITCH ENV | Bypass が入っているあいだ、中のつまみと波形のプレビュー |
| SSG SW AMP ENV / SSG SW AMP ENV[11] / SSG SW PITCH ENV[11] | Bypass が入っているあいだ、中のつまみすべて |
| N88 LFO / OPZX7 の LFO / OPM の LFO | PM 側は PM Enable、AM 側は AM Enable に従う。両方で使うもの（速さ・形・同期）は、どちらかが入っていれば押せる |
| FIX | Enable が切れているあいだ、中のつまみと区切り線 |

TARGET で指し先を切り替えたときや、プリセットを読み込んだときも、指し先の
札に合わせて止まります。

## PCM の QUALITY にノイズリダクションを足しました

**ADPCM / ADPCM+ / RHYTHM の QUALITY に、雑音を抑える設定を足しました。**
どれも初期は切ってあるので、これまでの音は変わりません。

| つまみ | 内容 |
| --- | --- |
| **NR: Resample** | 圧縮方式（BIT の 13〜21）へ変換するときの間引きを、きれいなもの（窓付き sinc）にする。圧縮方式を選んでいるときだけ押せる |
| **NR: Gate** | 無音に近いところのかすかな雑音を消す。直流も取り除く |
| **GATE.LV** | ゲートが閉じる音量（dB）。-96 〜 -24、初期値 -60。NR: Gate が入っているときだけ押せる |
| **NR.LPF** | 高い音を切って、ざらつきを抑える。切 / 弱 / 中 / 強 |

雑音の量も測り直しました。ビット数を落とすもの（BIT の 1〜12）は理屈どおりの
量でした。圧縮方式は、変換のときの間引きが粗く、どの設定でも信号とひずみの比が
28 dB ほどで頭打ちになっていました。**NR: Resample** を入れると 90 dB ほどまで
よくなります。

- 設定は QUALITY のファイルと CH Params に保存されます
- RHYTHM のパッドの写し（COPY / PASTE）に、INTERP とノイズリダクションも
  入るようにしました。これまでは BIT と RATE だけでした

## 直したところ

- **86V の N88 LFO のファイルが、3.0.0 の形式になっていなかったのを直しました。**
  古い行の形式でしか読み書きできず、2686V などで書き出した N88 LFO のファイルを
  読めませんでした。ほかのプラグインと同じ形式で読み書きし、古い形式のファイルは
  読んだうえで新しい形式へ書き直します
- ホールドと部分再生の **HOLD** / **KEEP** を切り替えても、すぐに反映されなかった
  のを直しました。SSG HW AMP ENV・SSG HW PITCH ENV では HOLD を切り替えても波形の
  プレビューが変わらず、WT AMP MOD・WT PITCH MOD などでは KEEP を入れても START や
  END が押せないままでした。どちらも、ほかのつまみを触るまで古い状態のままでした
- **2686VFX** のエフェクターの枠の順番の一覧で、PCM ビットクラッシャーの行に
  名前が出ていなかったのを直しました
- QUALITY と QUALITY(PCM) の RATE の選択肢で、「5.5kHz」と「4kHz」の番号が
  ずれて（12 と 13 に）いたのを、13 と 14 に直しました。表示の番号だけの誤りで、
  選ばれる周波数は変わりません

## 開発まわり

ソースからビルドする人向けの変更です。

- **テストを、ふだんのビルドから外しました。** ビルドのプリセットで、テストも
  組むかどうかを選びます

  | ビルドのプリセット | 組むもの |
  | --- | --- |
  | `*-debug` | プラグインとテスト |
  | `*-release` | プラグインだけ |
  | `*-release-tests` | プラグインとテスト（新設） |

  テストだけを組むときは `--target AllTests` を指定します
- N88 LFO の画面を、ほかの区分と同じく部品にしました（見た目と動きは同じ）
- 札に合わせてつまみが止まるか、キーアサインが割り当てどおりに動くかを、
  実際の画面とプロセッサで確かめるテストを足しました
