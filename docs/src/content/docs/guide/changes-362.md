3.6.1 から 3.6.2 までの変更をまとめます。**読み込めなくなるファイルはありません。**
ただし、直した不具合のうち 3 つは音が変わります（下の各節に書いてあります）。

## ポリフォニックで短い音符を続けて弾くと重くなるのを直しました

**ポリフォニックでは、最大同時発音数（10 音）を超えて最大 80 音まで重なって
いました。**

ボイスは「最大同時発音数 10 × ユニゾンの最大 8」の 80 本を用意しています。
ポリフォニックでは、この 80 本をすべて使って音を割り当てていたため、ユニゾンが
1 のときでも 80 音まで重なりました。短い音符を続けて弾くと、前の音の余韻
（リリース）が残ったまま次のボイスが使われていき、80 音近くまで積み上がって
処理が追いつかなくなっていました。

3.6.2 では、同時に鳴らすボイスを「10 × ユニゾン数」までにしました。超えたときは
古い音から譲ってもらいます。離したあとの余韻に入っている音を先に選び、押さえて
いる音はなるべく切りません。

| 例（OPNA、10ms あたりの処理時間） | 3.6.1 | 3.6.2 |
| --- | --- | --- |
| ユニゾン 1 で鍵盤を次々に押したまま 6 秒 | 13.9ms | 1.8ms |

:::note[音が変わる場合]
10 音を超えて重なっていたところは、古い音の余韻が早めに切れます。
:::

ユニゾンを掛けると、そのぶんボイスを使います（ユニゾン 8 なら 10 音 × 8 = 80
本）。重い音色でユニゾンを多く掛けて和音を弾くと、処理が重くなるのは変わりません。

## RHYTHM の MUL/DET と FIX が効くようにしました

**RHYTHM のパッドでは、MUL/DET と FIX を動かしても音の高さが変わりません
でした。**

パッドは素材をそのままの高さで鳴らします。MUL/DET と FIX で動かした周波数を、
再生の速さへ掛けていませんでした（ノイズと変調の速さにだけ効いていました）。
3.6.2 では、動かした周波数と元の周波数の比を再生の速さへ掛けます。

- MUL の ×2.0 で 1 オクターブ上がります
- FIX は、パッドを割り当てた鍵盤の高さを基準に、決めた周波数の高さで鳴ります

ほかの非 FM チャンネル（SSG / BEEP / WT / WT2 / WT+ / ADPCM / ADPCM+）も
すべて鳴らして確かめ、こちらはどれも効いていました。

:::note[音が変わる場合]
RHYTHM で MUL/DET・FIX を既定以外にしていたパッドは、音の高さが変わります。
既定のままのパッドは変わりません。
:::

## PCM 系で、鳴らしている最中に QUALITY を変えると音の高さがずれるのを直しました

**RHYTHM / ADPCM / ADPCM+ で、音を鳴らしたまま QUALITY を変えると、その音が
鳴り終わるまで高さがずれていました。**

QUALITY で符号化するモードを選ぶと、決めた標本化周波数へ落とした素材を
読みます。QUALITY を変えると読む素材が差し替わりますが、鳴っている音は発音した
ときの再生の速さのままでした。たとえば Raw（元の 44.1kHz）から 16kHz の
YM2608 ADPCM へ替えると、約 2.8 倍の速さで読んで高くなっていました。次に押した
音からは正しい高さでした。

3.6.2 では、鳴っている音も差し替わった素材に合わせて、再生位置と速さを数え
直します。

## MUL/DET・FIX を鳴らしながら反映できるようにしました

MUL/DET と FIX は、すべてのチャンネル（FM のオペレータを含む）で**押したときの
値**で音の高さを決めています。鳴らしている最中に動かしても、効くのは次に押した
音からでした。

SETTINGS に「MUL/DET・FIX を鳴らしながら反映」を足しました。入れると、鳴って
いる音にもその場で効きます。実機でレジスタを書き換えたときと同じ効き方です。
位相はそのまま引き継ぐので、動かした瞬間に音が途切れることはありません。

初期状態は切で、これまでと同じく押したときの値のまま鳴ります。オートメーション
で MUL/DET・FIX を動かしているプロジェクトは、入れると鳴り方が変わります。

2686VFX の MUL/DET は、もともと動かしたその場で効くので、この設定はありません。

## 2686VFX

### 出力の音量（LEVEL）を足しました

エフェクターの全体のバイパスの下に **LEVEL** を足しました。つまみはチャンネルの
LEVEL と同じもので、0.0〜10.0 の倍率、初期値 1.0 です。オートメーションは
`FX_LEVEL`、FX のパラメータファイル（`.2fx`）には `output.level` で保存します。

### 出力が小さかったのを直しました

**入力を 1/4（−12dB）に絞っていたため、効果を何も入れなくても出力が小さく
なっていました。**

音源と同じ「ヘッドルーム」を掛けていたのが原因です。音源は声を重ねて大きく
なるぶんを下げるために使いますが、2686VFX は声を重ねないので要りません。
2686VFX ではヘッドルームをやめ、SETTINGS の「ヘッドルームを確保」「ヘッド
ルームゲイン」の欄も外しました。音量は LEVEL で決めてください。

:::note[音が変わる場合]
2686VFX を使っているプロジェクトは、出力が 12dB（4 倍）大きくなります。
これまでと同じ大きさにするには、LEVEL を 0.25 にしてください。
:::

### 全体のバイパスが効いていなかったのを直しました

**全体のバイパスを入れても、音が変わったままでした。**

バイパスは効果の中だけで見ていたので、その手前のヘッドルームと出力への変調が
掛かったままでした。3.6.2 では、全体のバイパスを入れると、変調・効果・LEVEL の
どれも通さず、入ってきた音をそのまま返します。
