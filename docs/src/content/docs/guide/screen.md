どのプラグインも画面の作りは同じです。ここでは共通の部分をまとめます。

## 大きな区切り

音源のプラグインは、**左のタブと右の FX ペイン**に分かれています。

<figure class="shot">
	<img src="/2686V_2686VFX/ui/parts/tab_area.png" alt="画面の大きな区分け" />
	<figcaption>タブとペイン</figcaption>
</figure>

| 場所 | 中身 |
| --- | --- |
| 左（タブ） | 音源チャンネルと、ADV / PRESET / SETTINGS / COLORS / ABOUT |
| 右（ペイン） | FX。**タブを切り替えても出しっぱなし**です |

FX が常に見えているのは、どの音源を触っていてもエフェクトを調整できるように
するためです。

:::note
**2686VFX では FX がタブになります。** 音源タブが無いので、ペインとして脇に
置く必要がないためです。
:::

## タブ

<figure class="shot">
	<img src="/2686V_2686VFX/ui/parts/tabs.png" alt="各種タブ" />
	<figcaption>タブの一覧(2686V)</figcaption>
</figure>

左から順に並びます。収録されるものはプラグインによって違います
（[プラグインの選び方](/2686V_2686VFX/plugins/compare/)）。

### 音源のタブ

OPNA / OPN / OPL / OPL3 / OPM / OPZX7S / SSG / WT / WT2 / WT+ / RHYTHM /
ADPCM / ADPCM+ / BEEP

**同時に鳴るのは、開いているタブの音源 1 つだけです。** 重ねたいときは DAW の
トラックを分けます。

タブの色はチャンネルの系統ごとに変えてあるので、FM 系・SSG 系・波形メモリ系・
PCM 系が色で見分けられます。

### 音源以外のタブ

| タブ | 中身 |
| --- | --- |
| **ADV** | カーブ編集。値の変化のしかたを決めます (2686V / OPNV / OPLV / OPM / OPZX7S / PULSEV / WTV / PCMV) |
| **PRESET** | プリセットの保存・読み込み、お気に入り、履歴、形式とチャンネルでの絞り込み |
| **SETTINGS** | 動作の設定、フォルダの場所、ファイル形式 |
| **COLORS** | 画面の色の変更 |
| **ABOUT** | 版とライセンスの表示 |

## FM と RHYTHM のタブ — エンベロープグラフと TARGET

OPNA / OPN / OPL / OPL3 / OPM / OPZX7S / RHYTHM のタブは、**上にエンベロープグラフ、下に設定ひとそろい**という作りです。設定はオペレーター（パッド）の数だけ並べず 1 組だけ置き、**TARGET** でどれを指すかを切り替えます。

<figure class="shot">
	<img src="/2686V_2686VFX/ui/channel/ch_opzx7s.png" alt="OPZX7Sチャンネル" style="width:600px;" />
	<figcaption>OPZX7S。上の枠に WAVE SHAPE の波形とエンベロープが出る</figcaption>
</figure>

| ところ | はたらき |
| --- | --- |
| 上の枠 | オペレーター（パッド）ごとのエンベロープグラフ。横 4 枚ずつ並びます。**押すとそこへ TARGET が移ります** |
| 枠線 | TARGET が指している枠だけ濃く囲います |
| TARGET | 下の設定が指しているオペレーター（パッド）。画面を閉じても覚えています |
| 名前 | TARGET の右に、指しているものの名前（「オペレーター1」「Pad 1 (BD)」など）が出ます |
| AMP / PIT / SSG / S11 / P11 | 上のエンベロープグラフに**どのエンベロープを映すか**。枠ごとではなく全部まとめて切り替わります |
| 設定の列 | 区分が横へ 1 列ずつ並びます。あふれたぶんは下の送り棒で送ります |

エンベロープグラフに出るものはタブによって少し違います。

| タブ | 枠に出るもの |
| --- | --- |
| OPNA / OPN / OPL / OPL3 / OPM | エンベロープ |
| OPZX7S | WAVE SHAPE の波形とエンベロープ |
| RHYTHM | 読み込んだ音声の波形とエンベロープ |

切り替えの札を枠ごとに持たせていないのは、並べたエンベロープグラフが**見比べるため**の
ものだからです。一枚ずつ違うものを映すと比べようがありません。

設定の列は最初から開いた状態です。縦に短い区分は、いくつかを 1 列へまとめて
あります（たとえば OPN の「KEY SCALE / MUL/DET / FIX / N88 LFO」）。

TARGET は **Ctrl + ← / →** でひとつずつ、**Ctrl + 数字**でその番号へ動かせます
（[ショートカットキー](/2686V_2686VFX/reference/shortcuts/)）。

## 共通の部品

### カテゴリの見出し

中身のまとまりごとに見出しが付きます。**左端のランプで開閉が分かります。**
見出しを押すと開閉します。

開いているあいだは、中身の後ろに板が敷かれます。どこまでがそのカテゴリかを
目で追えるようにするためです。

見出しの**色は種類を表します。**

| 色 | 意味 |
| --- | --- |
| 黄色 | 実機にあった機能 |
| 青色 | 音量にかかわるもの（AMP ENV / SSG SW AMP ENV / WT AMP MOD など） |
| ターコイズ | 音程にかかわるもの（PITCH ENV / SSG SW PITCH ENV / WT PITCH MOD など） |
| 紫色 | LFO |
| シアン | 上のどれでもないもの（OPTIONAL / UNISON・HARMONY / FIX / MUL・DET） |
| 赤色 | 音質にかかわるもの（QUALITY） |
| 黄緑 | このプラグインで足した、そのほかの機能 |
| オフホワイト | 大区分（下記） |

青・ターコイズ・紫・シアンは、どれも**当時のドライバがソフトで実現していた
機能**か、このプラグインで足したものです。数が増えて水色ひと色では見分けが
付かなくなったので、3.1.0 から役割ごとに色相を分けています。

並ぶ順番も系統ごとにまとまっていて、**ハードウェア由来のものが上**、
そのあとに音量系・ピッチ系・LFO と続きます。

### 大区分 — [[AMP ENV]] / [[PITCH ENV]]

チャンネル全体に掛かる区分のうち、音量にかかわるものは **[[AMP ENV]]**、
音程にかかわるものは **[[PITCH ENV]]** という見出しの下へまとめてあります。
区分の数が多く、縦に並べると目で追いにくいためです。3.4.0 で足しました。

<figure class="shot">
	<img src="/2686V_2686VFX/ui/parts/major_category.png" alt="大区分" style="width:212px;" />
	<figcaption>SSG の [[AMP ENV]] を開いたところ。[[PITCH ENV]] は閉じている</figcaption>
</figure>

| 大区分 | 中に入る区分 |
| --- | --- |
| **[[AMP ENV]]** | AMP ENV / SSG HW AMP ENV / SSG SW AMP ENV / SSG SW AMP ENV[11] / WT AMP MOD |
| **[[PITCH ENV]]** | PITCH ENV / SSG HW PITCH ENV / SSG SW PITCH ENV[11] / WT PITCH MOD |

- 対象は OPNA / OPN / OPL / OPL3 / OPM / OPZX7S / SSG / WT / WT2 / WT+ /
  ADPCM / ADPCM+ / BEEP のタブです。区分の並び順は変わりません
- 中に入るのは、そのタブが持っている区分だけです。FM 音源のタブには、
  チャンネル全体の SSG SW AMP ENV と PITCH ENV がありません
- 見出しは下地がオフホワイトです。ランプの色と、押して開閉するのは
  ほかの見出しと同じです
- **最初は閉じています。** 開くと、中の区分が板の上に並びます
- 簡易表示モードで中の区分がすべて隠れたときは、大区分の見出しごと隠れます
- 大区分を閉じても**音は変わりません**

### 言語の切り替え

画面の表示言語を日本語と英語から選べます。SETTINGS タブの先頭にあります。

選択肢の名前は、日本語は「日本語」、英語は「English」と、その言語自身の表記で固定に
なっています。これは、読めない言語へ間違えて切り替えてしまった場合でも、元の言語に
戻せるようにするためです。

初期状態では、OS の言語設定から自動的に判断されます（日本語以外はすべて英語になります）。
切り替えると画面が新しく組み直されます。

### 簡易表示モード

区分が増えて 1 つのタブが縦に長いので、**よく使うものだけ残して畳む**
切り替えを SETTINGS に置いてあります。**出しているものを隠すだけで、音は
変わりません。** 隠した区分の値もそのまま残ります。

はじめて画面を開いたときに、入れるかどうかを尋ねます
（[初期設定の問い](/2686V_2686VFX/guide/install/#初期設定の問い)）。

何を隠すかはタブごとに決めてあり、**そのチャンネルが実機の機能として
持っている区分は残します。** SSG では SSG HW AMP ENV が、WT / WT2 / WT+ では
WT PITCH MOD が残るのはそのためです。2686VFX では変調の枠が隠れ、効果の枠は
残ります。

スイッチを入れると、下に **簡易表示モードカスタマイズ** が出ます。ここで
入れた区分は、簡易表示モードでも隠れません。

| 区分 |
| --- |
| AMP ENV / SSG HW AMP ENV / SSG SW AMP ENV / SSG SW AMP ENV[11] / WT AMP MOD |
| PITCH ENV / SSG HW PITCH ENV / SSG SW PITCH ENV[11] / WT PITCH MOD |
| LFO / MUL・DET / FIX / UNISON・HARMONY |

設定は他の項目と同じく設定ファイルへ保存されます。

FM と RHYTHM のタブのように区分を横へ並べているところでは、**隠した区分は
列ごと消え、右の列が左へ詰まります。**

#### 隠した区分を切る

隠れているのは表示だけなので、**音は隠す前と同じまま**です。まとめて切りたい
ときは、「簡易表示モード」の右隣にある **[非表示中の区分をバイパス]** を押します。
いま隠れている区分だけが切れ、カスタマイズで出したままにしている区分は
そのまま残ります。簡易表示モードが切ってあるあいだは押せません。

入り切りの札を持たない **MUL・DET** と **UNISON・HARMONY** は、値しか持たない
ので触りません。**LFO** は PM と AM の両方が落ちます。

#### 区分をまとめて開閉する — OP / CL

画面右上の **[OP]** と **[CL]** で、区分の開閉をまとめて整えられます。対象は
簡易表示モードで隠す区分と同じで、**全チャンネル・全オペレータ・全パッドに
一度で効きます。**

| ボタン | はたらき |
| --- | --- |
| **OP** | 切っていない区分を開きます |
| **CL** | 切ってある区分を閉じます |

「使っているものだけ開いた状態」に一発で整えたいときに使います。簡易表示
モードが切ってあっても押せます。入り切りの札を持たない区分は、どちらの
ボタンでも触りません。

大区分は、中の区分に合わせて開閉します。**OP** では中に切っていない区分が
1 つでもあれば開き、**CL** では中の区分がすべて切ってあれば閉じます。

### スライダー

つまみを動かすか、数値を直接打ち込めます。

- **ボタンにマウスを乗せる**と、その値の範囲が出ます（SETTINGS で切り替え可）
- ダブルクリックで初期値へ戻ります

### ナッジ

スライダーの脇にある小さなボタンで、値を少しずつ動かせます。**「N」ボタンで
表示・非表示を切り替えられます。** 使わないときは畳んでおくと画面が広く使え
ます。

LEVEL には **Steps** による段階入力もあります。LEVEL の N で出るボタンには、
±1.0 / ±0.1 / ±0.01 で動かすものと、1.0・0.5・0.25 などへ直に置くものが
あります。RHYTHM のパッドの LEVEL も同じです。

### 生成波形のプレビュー

今のチャンネルの設定で実際に鳴らした波形を、**L / M / R の 3 段**で出します。
作るのは**生成**ボタンを押したときだけです。演奏中に作り続けることはしません。

長さは最大 10 秒で、途中で鳴り終われば、そこから 0.5 秒で打ち切ります。短い
音を 10 秒ぶん作っても、頭の一瞬だけ動いて、あとは止まった線が続くだけになる
ためです。

1 / 2 / 5 / 10 周期から選べます。周期に合わせた位置から出すので、波形が横へ
流れていきません。

作ったものはファイルへ貯めるので、次に開いたときは作り直しません。貯めた
ものは SETTINGS の「プレビュー波形の全削除」でまとめて消せます。

## ファイルブラウザー

プリセット・パラメータ・波形・音の素材のどれを読み書きするときも、画面を
ほぼ覆う一覧が出ます。

| ところ | はたらき |
| --- | --- |
| キーワード | 打っている間だけ、下のフォルダまで潜って探します |
| 区分 | OPNA / OPM / 波形(WT) といった種類で絞ります |
| ファイル形式 | JSON / YAML / 無印で絞ります |
| 見出し | 押すたびに「並べ替えなし → 昇順 → 降順」と回ります |
| フォルダ… | 遠くのフォルダへ一息で移ります |
| 新規フォルダ / フォルダ削除 | 今いるところにフォルダを作る・消す |
| 生成 / 再生成 | その行の波形プレビューを作ります |
| 一括生成 / 一括削除 | 今のフォルダぶんをまとめて作る・消す |

行は**ダブルクリック**で選びます。フォルダも同じで、一度押すと選ばれ、二度
押すと中へ入ります。一番上の「上へ」で親フォルダへ戻ります。

パラメータ・プリセット・波形は、**プラグインの置き場より上のフォルダへは
行けません**。外へ出ても選べるファイルが無いためです。音の素材 (wav) は、
どこから持ってきても構わないので縛っていません。

外側を押すと、選ばずに閉じます。

## 鍵盤

画面の下に MIDI 鍵盤を出せます。DAW から MIDI を送らなくても、その場で音を
確かめられます。SETTINGS で出し入れします。

キーボードからの操作は
[キーボードショートカット](/2686V_2686VFX/reference/shortcuts/) を参照して
ください。
