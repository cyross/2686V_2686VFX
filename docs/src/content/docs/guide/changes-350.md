3.4.0 から 3.5.0 までの変更をまとめます。**読み込めなくなるファイルはありません。**
3.4.0 までに作ったプリセットやパラメータファイルは、そのまま読めます。

## 画面の表示言語を切り替えられるようにしました

**画面の文字を日本語と英語で切り替えられるようにしました。**

- **SETTINGS** タブの先頭に「言語 (LANGUAGE)」の選択を足しました。日本語と英語から
  選べます。選択肢はそれぞれ「日本語」「English」というその言語での表記で固定して
  あるため、読めない言語へ間違えて切り替えても迷わず戻せます
- 書かれていないときは、OS の言語から見立て、日本語以外はすべて英語になります
- 切り替えると画面を組み直すため、即座に言語が反映されます
- この切り替えは、ファミリーのプラグインすべて（12本）で同じように動きます

## ABOUT にマニュアルへのリンクを足しました

**ABOUT タブに、このユーザーズマニュアル（Web サイト）を開くボタンを足しました。**

- SETTINGS で選んでいる言語に合わせて、日本語のときは日本語版、英語のときは
  英語版 (/en/) のマニュアルを開きます

## そのほか調整したところ

- **PRESET** の「形式」のラベルの幅を、英語の "Format" が収まるよう少し広げました
- 英語の "Waveform preview" が枠に収まるよう、波形プレビューの見出しの括弧書き
  「（オシロスコープ）」は日本語のときだけ出すようにしました
