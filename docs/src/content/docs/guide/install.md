## 置き場所

VST3 は、DAW が読みに行くフォルダへ置きます。Windows の標準は次の場所です。

```text
C:\Program Files\Common Files\VST3
```

スタンドアロン版は、任意の場所へ置いて実行できます。

## はじめて起動したとき

起動すると、ドキュメントフォルダの下に作業用のフォルダが作られます。

```text
(ドキュメント)\2686V\
```

**このフォルダは 12 のプラグインで共通です。** プリセットや設定、書き出した
パラメータファイルはすべてこの下に置かれます。中身は
[ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を参照してください。

### 初期設定の問い

はじめて画面を開くと、**「初期設定」** というダイアログで次のように尋ねます。

> パラメータを簡易表示モード(必要最低限のパラメータのみ表示)で表示しますか？

| 答え | どうなるか |
| --- | --- |
| **はい** | 簡易表示モードを入れて、標準設定のファイルを作ります |
| **いいえ**（ESC で閉じたときも） | 簡易表示モードを切って、標準設定のファイルを作ります |

どちらを選んでも、あとから SETTINGS の **「簡易表示モード」** で切り替え
られます。簡易表示モードは区分の一部を隠すだけで、音は変わりません。

標準設定のファイル (`init.settings.json`) は 12 のプラグインで共通です。
どれか 1 本で答えれば、ほかのプラグインでは尋ねません。答える前に画面を
閉じたときは、ファイルを作らず、次に開いたときにまた尋ねます。

:::note[もう一度尋ねてほしいとき]
すべてのプラグインを閉じてから、`(ドキュメント)\2686V\init.settings.json`
（YAML を選んでいるときは `init.settings.yaml`）を別の名前へ変えるか消します。
標準設定がまるごと初期値へ戻るので、残しておきたい設定があるときは名前を
変えて取っておき、答えたあとで SETTINGS の「設定ファイルから読み込み」で
読み戻してください。
:::

## 設定の保存

画面で変えた設定は、その場では保存されません。SETTINGS タブの
**「標準設定として保存」** を押すと、次回の起動から使われるようになります。
