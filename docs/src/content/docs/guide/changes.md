2.5.1 から 3.0.0 までの変更をまとめます。**先に読んでおいたほうがよいのは
[移行のときに気をつけること](#移行のときに気をつけること)** です。

## いちばん大きな変更

### プラグインが 1 つから 5 つに

2.5.1 は **2686V** だけでした。3.0.0 では役割ごとに分かれています。

| プラグイン | 内容 |
| --- | --- |
| 2686V | すべてを収録した本体 |
| 2686VLight | カーブ編集を外した軽い版 |
| 86V | PC-9801-86 に構成を合わせた版 |
| OPZX7S | OPZX7 音源に特化。カーブ編集は標準 |
| 2686VFX | 音を加工するエフェクト |

どれを選ぶかは
[プラグインの選び方](/2686V_2686VFX/plugins/compare/) を参照してください。

### ファイルの形式が JSON と YAML に

プリセットもパラメータも、`JSON` か `YAML` で読み書きするようになりました。
どちらを使うかは設定で切り替えます。中身が読める形なので、テキストエディタ
で直したり差分を取ったりできます。

## 音づくり

### OPZX7S 音源の強化

- **最大 8 オペレータ**に拡張
- **アルゴリズムマトリックス** — 変調とフィードバックの経路をチェックボックス
  で自由に組める。従来の仕様ではあり得ない結線もできる
- **フィードバックをオペレータごとに独立して設定可能**（実数、-8.0〜8.0）
- アルゴリズム図を画像からリアルタイム描画へ変更。従来のアルゴリズムも図で
  表示される
- LFO に独自波形を追加

### エンベロープの拡充

- **11 タップのエンベロープを追加** — SSG SW ENV11（音量）と
  SSG SW PENV11（音程）
- **SSG ハードウェアエンベロープを全チャンネルへ**。あわせて独自波形を 36 種
  追加し、範囲の MIN / MAX も指定できるようになりました
- **FM 音源にチップ全体へ掛かるエンベロープを追加** — AMP ENV / SSG HW AMP ENV
  / SSG SW ENV11 / PITCH ENV / SSG SW PENV11
- チップ全体のエンベロープの動きを見るグラフを追加

### 波形メモリのピッチモジュレーション

- **FDS / WonderSwan / HuC6280 の変調方式を追加**
- FDS の変調テーブルを 32 エントリでその場で編集できる
- HuC6280 モードは変調波形を 8 枚まで持て、リアルタイムに切り替えられる
- **FM / SSG / RHYTHM / ADPCM / BEEP のすべてで使える**ようになりました

### 新しいチャンネル

- **WT+** — `.wt` / `.wt2` の波形を最大 32 まで読み込み、スライダーや
  オートメーションでリアルタイムに切り替えられます

### そのほか

- PCM 系のビットに各種 ADPCM の品質を追加
- BEEP の音質を改善し、設定を追加
- **UNISON / HARMONY を拡張** — 疑似高速アルペジオ、ボイス単位のデチューンと
  定位
- リズムパッドの名称を YM2608B を基準に見直し
- OPN↔OPNA 間、OPL↔OPL3 間でパラメータをインポートできるようになりました

## 画面

### COLORS タブを新設

画面に使う色をひとつずつ変えられます。RGB / HSV のほかに、**色名（JUCE と
独自）と実機のパレット**（PC-8801 / PC-9801 / X68000 / PC エンジン /
メガドライブ）から選べます。ボタンひとつで初期値に戻せます。

設定はファイルへ保存され、変更はすぐ画面へ届きます。

### 見た目の刷新

- カテゴリの見出しを描画ベースに変更。**開閉の表示を文字からランプへ**
- 開いた中身の背後に板を敷いて、どこまでがそのカテゴリか分かるように
- 面を持つ部品とスライダーに影を追加
- タブの幅を、実際に描く文字で測るようにして名前が省略されないよう修正
- ウィンドウ幅・各グループ幅を拡大
- **ナッジボタンの表示・非表示を「N」ボタンで切り替え**
- チャンネルごとにタブとカテゴリの色を変更
- 波形プレビューを大幅に増やしました

### PRESET タブの拡張

- **お気に入り**と**読み込み履歴**を追加（どちらも数の上限なし）
- すべて / お気に入り / 履歴 で表示を切り替え
- 検索でお気に入り・履歴を絞り込める

## エフェクトプラグイン 2686VFX

v2.x.x で外していたエフェクトプラグインが戻ってきました。2686V の FX ペインを
そのまま持ち、さらに音源側のエンベロープや LFO を**出力そのものへ掛けられ
ます**。

- **PCM ビットクラッシャー** — 2686VFX だけの効果。実機のレートとビットの刻み
  で落とします
- 出力への変調 9 種を追加。MIDI の鍵盤で動きます
- FX の順番のファイルは、音源側と行き来できます

詳しくは [2686VFX (エフェクト)](/2686V_2686VFX/plugins/fx-plugin/) を
参照してください。

## そのほか

- **このマニュアルサイトを新設**しました。オートメーションの一覧も載せています
- レベルの刻み入力（Steps）を追加
- チャンネル・オペレータ・パッド単位でパラメータをインポート・エクスポート
  できるようになりました
- Windows ARM64、Linux、macOS のビルド設定を用意（macOS では AU も出ます）

## 主な不具合修正

- AMP ENV の STL がまったく反映されていなかったのを修正
- カーブが index に関係なく効くようにし、OPZX7S のエンベロープを揃えた
- カーブのアタックが線形より 1 サンプル遅れていたのを修正
- OPZX7 LFO の Sample & Hold が、サイクルではなくサンプルを数えていたのを修正
- SSG SW 系エンベロープの STEP 操作で画面が固まるのを修正
- DAW に出るパラメータ名の抜けと重複を修正
- 桁の多いスライダーで数値が省略されていたのを修正
- プリセット一覧の作り直しとパラメータのコピーが待たされていたのを高速化

## 移行のときに気をつけること

:::caution
**古い形式のファイルは読み込めますが、書き出しは新しい形式になります。**
:::

| 種類 | 3.0.0 での扱い |
| --- | --- |
| プリセット (`.xml`) | **読み込みのみ**。開いて保存し直すと新しい形式になります |
| パラメータファイル（プレーンテキスト） | 読み込むと**自動で変換**されます |
| 波形メモリ (`.wt` / `.wt2`) | **変わりません**。今までどおりの形式のままです |

- プリセットの拡張子は**プラグインごとに違います**。別のプラグインのプリセット
  は一覧に出ません
- ただし **FX の順番とパラメータのファイルは共通**で、5 つのプラグインの
  あいだで行き来できます

詳しくは
[ファイルの形式と置き場所](/2686V_2686VFX/files/format/) と
[旧形式からの変換](/2686V_2686VFX/files/convert/) を参照してください。
