## 主な特徴

### 実機に寄せつつ、足りないところは足す

FM・SSG・波形メモリ・ADPCM といった当時の音源を、それぞれ**チャンネル**として
持っています。実機にある機能は実機の仕様どおりに動き、そのうえで当時は
できなかったことを独自の拡張として足してあります。

どこが実機でどこが独自かは、画面の見出しの色とマニュアルの表記で見分けられ
ます。実機の音を狙うときは独自の項目に触らなければ済みます。

### エンベロープが厚い

音量と音程のどちらにも、複数のエンベロープを重ねられます。

- アンプエンベロープ（ADSR）
- SSG ハードウェアエンベロープ（波形を独自に追加）
- SSG ソフトウェアエンベロープ（6 タップ / 11 タップ）
- ピッチエンベロープ（3 タップ / 11 タップ）
- 波形メモリによるピッチモジュレーション

これらは**すべてのチャンネル・オペレータ・リズムパッド**で使えます。当時の
音源ドライバがソフトウェアで実現していた小刻みな音の動きを、そのまま画面から
組めます。

### 波形を目で見て作れる

読み込んだ音声ファイル、波形メモリ、エンベロープのグラフを画面で確認できます。
数値だけで組み立てずに済むので、狙った形になっているか確かめながら進められ
ます。

### 色を全部変えられる

COLORS タブで、画面に使う色をひとつずつ変えられます。RGB や HSV のほかに、
**PC-8801 / PC-9801 / X68000 / PC エンジン / メガドライブ**のパレットから
選べます。ボタンひとつで初期値に戻せます。

### ファイルは JSON か YAML

プリセットもパラメータも、`JSON` と `YAML` のどちらでも読み書きできます。
設定で切り替えます。中身が読める形なので、テキストエディタで直したり、
差分を取ったりできます。

## こんなときに向きます

### 当時の機材の音で曲を作りたい

**86V** が近道です。PC-9801-86 の構成に合わせてあるので、当時存在しなかった
選択肢が最初から出てきません。迷いどころが減ります。

より広く当時の音を扱いたいときは **2686V**、カーブ編集を使わず軽く動かしたい
ときは **2686VLight** です。

### FM 音源をじっくり作り込みたい

**OPZX7S** です。最大 8 オペレータ、アルゴリズムマトリックスによる自由な結線、
オペレータごとに独立したフィードバックまで踏み込めます。カーブ編集も標準で
付きます。

### 手持ちの音をレトロに加工したい

**2686VFX** です。音を作らず、入ってきた音を加工します。ドラムのループでも
ギターでも、トラックに挿すだけで使えます。

音源側のエンベロープや LFO を**出力そのものへ掛けられる**のが特徴で、MIDI の
鍵盤で動かします。鍵盤を触らなければ素通しになるので、掛けたいところだけ
動かせます。

### 効果音を作りたい

各チャンネルの**効果音モード**と、BEEP チャンネルが使えます。SSG のノイズや
ビープ音は、当時のゲームの効果音そのものです。ピッチエンベロープを深く掛けると
レーザーや爆発の音になります。

### 既存の曲データを持ち込みたい

`.wt` / `.wt2` の波形メモリファイルを読み込めます。オペレータごとの **MML 入力**
もあるので、当時の書き方に慣れていればそちらから組めます。

## 向かないこと

- **1 つのプラグインで複数の音源を同時に鳴らすこと** — トラックを分けてください
- **完全な実機エミュレーション** — 音の雰囲気を再現するもので、レジスタ単位の
  互換性はありません
- **多声を重ねた重い曲を 1 トラックで** — 同時 10 声、ユニゾンと掛け合わせて
  最大 80 声まで鳴りますが、そのぶん負荷も上がります
