3.6.3 から 4.0.0 までの変更をまとめます。4.0.0 は「なるべくオートメーションを
使わずに、レトロゲームの作曲テクニックを形にする」ことを目指した大きな版です。

## ALGORITHM/FEEDBACK を開閉できるようにしました

OPNA / OPN / OPL / OPL3 / OPM / OPZX7（OPZX7S を含む）のグローバルにある
**ALGORITHM/FEEDBACK** の見出しを押すと、ほかの区分と同じく開閉します。
最初は開いています。閉じても音は変わりません。

## LEVEL / STEPS / DELAY を UNCATEGORIZED にまとめました

チャンネルのグローバルで、どの区分にも入っていなかった **LEVEL・STEPS・DELAY**
を、見出し **UNCATEGORIZED** の下へまとめました。全チャンネルが対象です。
開閉でき、最初は開いています。見出しを右クリックすると、ほかの区分と同じく
この 3 つだけを写すメニューが出ます。2686VFX の出力の LEVEL は変わりません。

## SSG に More Real FC / More Real NES を足しました

SSG の矩形波（デューティ比）設定で、FC FLUC の下に **More Real FC** と
**More Real NES** を置きました。ファミコン / NES（2A03）の矩形波の鳴り方を
真似ます。FC FLUC の揺らぎとは別物です。

- デューティ比は実機の 12.5% / 25% / 50% / 75% のうち最も近いもの
- 音程は 11bit タイマーの刻み。t が 8 未満の高い音は鳴らない
- 音量は 16 段で、DAC の曲がりを通す
- 出力のフィルタ: FC は 37Hz のハイパス、NES は 90Hz・440Hz のハイパスと 14kHz のローパス

FC Mode・More Real FC・More Real NES は、どれか 1 つだけ入れられます（すべて切も
かまいません）。初期状態は切で、既存のパッチの鳴りは変わりません。くわしくは
[SSG](/2686V_2686VFX/chips/ssg/) を参照してください。

## 区分の右クリックに複写・読み込み・書き出しを足しました

区分の見出しの右クリックメニューで、CLEAR の下に **複写 (DUPLICATE)**、
区切り線の下に **読み込み (IMPORT)** と **書き出し (EXPORT)** を置きました。

- **複写**: オペレーター・パッド・TARGET の区分を、同じチャンネルのほかの
  オペレーター・パッド・TARGET の同じ区分へ写します。写し先はチェックボックスの
  ダイアログで選びます
- **読み込み・書き出し**: UTILITY のその区分の [IM]… / [EX]… と同じです。
  UTILITY のボタンは残しています

くわしくは[区分を右クリック](/2686V_2686VFX/chips/common/#区分を右クリック)を参照してください。
