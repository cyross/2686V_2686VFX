3.6.3 から 4.0.0 までの変更をまとめます。4.0.0 は「なるべくオートメーションを
使わずに、レトロゲームの作曲テクニックを形にする」ことを目指した大きな版です。

## ALGORITHM/FEEDBACK を開閉できるようにしました

OPNA / OPN / OPL / OPL3 / OPM / OPZX7（OPZX7S を含む）のグローバルにある
**ALGORITHM/FEEDBACK** の見出しを押すと、ほかの区分と同じく開閉します。
最初は開いています。閉じても音は変わりません。

## LEVEL / STEPS / DELAY を UNCATEGORIZED にまとめました

チャンネルのグローバルで、どの区分にも入っていなかった **LEVEL・STEPS・DELAY**
を、見出し **UNCATEGORIZED** の下へまとめました。全チャンネルが対象です。
開閉でき、最初は開いています。見出しを右クリックすると、ほかの区分と同じく
この 3 つだけを写すメニューが出ます。2686VFX の出力の LEVEL は変わりません。

## SSG に More Real FC / More Real NES を足しました

SSG の矩形波（デューティ比）設定で、FC FLUC の下に **More Real FC** と
**More Real NES** を置きました。ファミコン / NES（2A03）の矩形波の鳴り方を
真似ます。FC FLUC の揺らぎとは別物です。

- デューティ比は実機の 12.5% / 25% / 50% / 75% のうち最も近いもの
- 音程は 11bit タイマーの刻み。t が 8 未満の高い音は鳴らない
- 音量は 16 段で、DAC の曲がりを通す
- 出力のフィルタ: FC は 37Hz のハイパス、NES は 90Hz・440Hz のハイパスと 14kHz のローパス

FC Mode・More Real FC・More Real NES は、どれか 1 つだけ入れられます（すべて切も
かまいません）。初期状態は切で、既存のパッチの鳴りは変わりません。くわしくは
[SSG](/2686V_2686VFX/chips/ssg/) を参照してください。

## 区分の右クリックに複写・読み込み・書き出しを足しました

区分の見出しの右クリックメニューで、CLEAR の下に **複写 (DUPLICATE)**、
区切り線の下に **読み込み (IMPORT)** と **書き出し (EXPORT)** を置きました。

- **複写**: オペレーター・パッド・TARGET の区分を、同じチャンネルのほかの
  オペレーター・パッド・TARGET の同じ区分へ写します。写し先はチェックボックスの
  ダイアログで選びます
- **読み込み・書き出し**: UTILITY のその区分の [IM]… / [EX]… と同じです。
  UTILITY のボタンは残しています

くわしくは[区分を右クリック](/2686V_2686VFX/chips/common/#区分を右クリック)を参照してください。

## SSG SW AMP / PITCH ENV[256] を足しました

3.6.3 までの SSG SW AMP ENV[11] / SSG SW PITCH ENV[11]（10 段 + リリース）を、
最大 **256 段**の SSG SW AMP ENV[256] / SSG SW PITCH ENV[256] に置き換えました。
全チャンネル・オペレーター・パッドと 2686VFX が対象です。

- STEP は 1〜256。リリースは **RR**（秒）と **LR**（行き先）で行います
- 段ごとの R / L は 256 段 × 2 あるので、パラメータではなく**表として**
  プリセットとチャンネルパラメータへ保存します。オートメーションでは動かせません
- 値の帯は STEP の段数ぶんだけ並びます
- 区分のパラメータファイルは `.ssgSwEnv256` / `.ssgSwPEnv256` です

**[11] で作ったものは読み込むときに [256] へ写します。** R1〜R10 / L1〜L10 が
1〜10 段に、R11 / L11 が RR / LR になり、同じように鳴ります。くわしくは
[SSG SW AMP ENV\[256\]](/2686V_2686VFX/chips/common/#ssg-sw-amp-env256) を
参照してください。

## 6 段の SSG SW AMP ENV をなくしました

3.6.3 までの 6 段（5 段 + リリース）の SSG SW AMP ENV をなくし、
[SSG SW AMP ENV\[256\]](/2686V_2686VFX/chips/common/#ssg-sw-amp-env256) にまとめました。
区分・グラフの「SSG」ボタン・UTILITY の [IM] / [EX]・簡易表示の項目・ADV のカーブの
対象 SsgSwEnv が無くなっています。

**6 段で作ったものは読み込むときに [256] へ写します。** プリセット・DAW の状態・
チャンネルパラメータ・`.ssgSwEnv`・カーブが対象です。

- R1〜R5 / L1〜L5 は 1〜5 段、R6 / L6（リリース）は RR / LR になります
- KEEP と Use Endl は切ります（6 段には無かったため）
- 6 段と [11] を**両方**使っていた音色は、[256]（もとの [11]）を残して 6 段を
  捨てます。2 つを掛け合わせた形は 1 つの [256] では表せないためです

あわせて、RHYTHM のパッドで鍵を離したときに [256] もリリースへ移るようにしました
（6 段は離していましたが、[11] は離していませんでした）。

## グループの幅を広げました

つまみや値の欄が窮屈だったので、グループの幅を 1.2 倍にしました。

- 全チャンネルのグローバルのグループ: 260 → 312
- オペレーター・パッドの列: 280 → 336
- SSG の「矩形波(デューティ比)設定」「三角波設定」: 250 → 300

## SSG に DUTY / PEAK RATIO ENVELOPE を足しました

矩形波のデューティ比と三角波の頂点を、時間で動かせるようにしました。どちらも
SSG SW AMP ENV[256] と同じ 256 段のエンベロープで、グループの一番下にあります。

- **DUTY RATIO ENVELOPE**（矩形波）: 値はデューティ比 0.0〜100.0%。入っているあいだは
  MODE・Invert Phrase の代わりに使います
- **PEAK RATIO ENVELOPE**（三角波）: 値は頂点の位置 0.0〜1.0。入っているあいだは PEAK の
  代わりに使います

一番上の **Enable** で入れます。初期状態は切で、既存のパッチの鳴りは変わりません。
くわしくは [SSG](/2686V_2686VFX/chips/ssg/) を参照してください。

## FM 音源のオペレーターに TL ENV を足しました

キーオンのたびに TL を書き換えて音量を動かす、ドライバでおなじみの手法を
**TL ENV** として描けるようにしました。SSG SW AMP ENV[256] の TL 版で、値は TL の
レジスタ値です。オペレーターの AMP ENV 区分のすぐ下にあります。

一番上の **Enable** で入れます。初期状態は切で、既存のパッチの鳴りは変わりません。
くわしくは [PARAM ENV\[256\]](/2686V_2686VFX/chips/common/#param-env256) を参照してください（4.3.0 で TL ENV は PARAM ENV の指し先 TL になりました）。

## FM 音源のチャンネルに ALG ENV を足しました

ALG（アルゴリズム）を段ごとに切り替える **ALG ENV** を足しました。SSG SW AMP ENV[256] の
ALG 版で、ALGORITHM/FEEDBACK の FEEDBACK の下にあります。発音の頭だけ繋ぎ方を変える、
といった使い方ができます。

一番上の **Enable** で入れます。初期状態は切で、既存のパッチの鳴りは変わりません。
くわしくは [ALG ENV](/2686V_2686VFX/chips/common/#alg-env) を参照してください。

## [[TAP SEQUENCER]] を足しました

鍵を押すたびに段を 1 つ進めて、音量（割合）や音程（セント）を補正する
**TAP AMP SEQUENCER / TAP PITCH SEQUENCER** を足しました。各チャンネルの [[PITCH ENV]] の下に
大区分 [[TAP SEQUENCER]] としてあります。2686VFX にも AMP / PITCH SEQUENCER があり、
キーアサインで動かす鍵盤を選べます。

あわせて、段の値の一覧を 1 行 4 個にし、「見出し: 値」を「 / 」で区切るようにしました。

**Enable** で入れます。初期状態は切で、既存のパッチの鳴りは変わりません。
簡易表示モードでは隠れます。出したままにしたいときは、SETTINGS の簡易表示モードカスタマイズで
**TAP SEQUENCER** を入れてください (2686VFX の AMP / PITCH SEQUENCER の枠も同じです)。
くわしくは [TAP SEQUENCER](/2686V_2686VFX/chips/common/#tap-sequencer) を参照してください。

## オペレーター / パッドのグラフを大きくしました

オペレーター / パッドのタブの上の絵を、**左に TARGET の大きな絵、右に全部の小さな絵**へ
組み替えました。大きな絵は TARGET を切り替えるとすぐにその内容になり、OPZX7S / RHYTHM では
波形も大きく出ます。小さな絵は OPNA / OPN / OPL3 / OPM が横 2 枚 × 2 段、OPL が横 2 枚 × 1 段、
OPZX7S / RHYTHM が横 4 枚ずつで、絵の縦横比は大きな絵とそろえてあります (波形の丈は変わりません)。
押すとそこへ TARGET が移ります。

## グラフを横に広げられるようにしました

チャンネルのグラフと、オペレーター / パッドの大きな TARGET の絵を、横へ 1.0〜32.0 倍に
広げられるようにしました。下のつまみかボタン（x1〜x32）、グラフの中のホイールで拡大率を変え、
右ボタンで引きずるか送り棒で横へ送ります。段の多い SSG SW ENV[256] なども細かく見られます。

## カーブ編集に編集ボタンを足しました

ADV のカーブ編集で、パラメータごとに **CUT・COPY・PASTE・DUPLICATE・CLEAR** を使えるように
しました。PASTE は Position・Target を問わず貼れ、DUPLICATE は同じ Target のほかのパラメータへ
まとめて写せます。くわしくは [ADV](/2686V_2686VFX/chips/adv/) を参照してください。

## TARGET の帯に板を敷きました

オペレーター / パッドのタブの一番上の帯 (TARGET・名前・グラフの切り替え) の背後へ濃い板を敷き、
壁紙が明るくても読めるようにしました。色は COLORS の `TargetRow.Bg` / `TargetRow.Border` で変えられます。

## 項目の欠けたプリセットを読むと、欠けたパラメータを初期値へ戻すようにしました

古い版で書いたプリセットや DAW の状態など、一部のパラメータを持たないものを読むと、
書かれていないパラメータが前に読んだプリセットの値のまま残っていました。そのまま保存すると
値の空な項目として書かれ、読み直すと 0 になっていました (STEPS が 10 から 1 になるなど)。
読むときに、書かれていないパラメータと値の空なパラメータを初期値にするようにしました。
すでに値の空な項目を含んで保存したファイルも、読むとその項目は初期値になります。
