3.6.2 から 3.6.3 までの変更をまとめます。**読み込めなくなるファイルはありません。**
既存のパッチの鳴りも変わりません。

## 2686VFX: 再生を止めると一瞬音が鳴るのを直しました

**DELAY / REVERB / SFC ECHO や変調（ENV・LFO・PITCH など）を使っていると、
再生を止めたときに一瞬音が鳴っていました。**

2686VFX は、残響が「無い」とホストへ伝えていました。Cubase などは、入力が無音に
なると VST3 の処理を止めます。再生を止めた途端に、ディレイや変調が溜めていた音を
持ったまま処理が止まり、次に動き出したときにその残りが一瞬出ていました。

3.6.3 では次の 2 つを直しました。

- 残響は「尽きない」ものとしてホストへ伝えます。止めたあとも残響は最後まで鳴ります
- ホストが処理を止めたときは、溜めてある音をすべて捨てます

## チャンネルパラメータを読み込むと、FM オペレーターのグラフが描かれないのを直しました

**チャンネルパラメータを読み込んだとき、TARGET で選んでいないオペレーターの
エンベロープのグラフが前のままでした。** TARGET を選び直すまで描き直されません
でした。

3.6.3 では、読み込んだあとにすべてのオペレーターのグラフを描き直します。
オペレーターのパラメータ（1 つぶん）を読み込んだときも、そのオペレーターの
グラフを描き直します。

## UNISON/HARMONY: P-SPREAD・P-DETUNE の対象に 0（元の音）を足しました

ボイスごとの P-SPREAD・P-DETUNE は、これまでボイス 1〜7 だけが対象でした。
3.6.3 では **VOICES で 0（元の音）も選べます**。元の音の位置や高さも、ほかの
ボイスと同じようにずらせます。

- 初期値は 0 で、これまでの音は変わりません
- オートメーションは `〜_UNI_PDIST0` / `〜_UNI_PDET0` です
- ファイルには `mainVoice` として書きます（`paraVoices` の並びはこれまでどおり
  ボイス 1〜7 です）

## アルゴリズムマトリックスとアルゴリズム図を詰めました

### マトリックス（OPZX7）

ルーティングとフィードバックのマトリックスを上下に 2 つ並べていたのを、
**スイッチで切り替えて 1 つずつ出す**ようにしました。上の **ROUTING /
FEEDBACK** のスイッチで、どちらを出すか選びます（ラジオボタンのように、どちらか
一方だけが点きます）。詰めたぶん、アルゴリズム図が上へ上がります。

どちらを出しているかは画面だけのもので、保存しません。

### アルゴリズム図（すべての FM チャンネル）

- オペレーターの箱を上下左右 2px ずつ小さくし、そのぶん箱どうしの間も詰めました
- 自分自身へのフィードバックの輪を、直径で 2px 小さくし、中心を箱の左上の角に
  合わせました
- 他のオペレーターへのフィードバックの線が横へ出る長さを 3px 縮めました
- 「FB」の文字をやめました（色と破線で見分けられます）
- OP8 の色を白へ寄せて、番号を読みやすくしました
- 図の高さも、そのぶん低くしました

## QUALITY に「DAC」を足しました

QUALITY（PCM 以外・PCM）と、2686VFX の PCM ビットクラッシャーの先頭に **DAC** の
行を足しました。機種を選んで **適応** を押すと、その機種の出力に合わせて
BIT RATE・SMP.RATE・INTERP をまとめて切り替えます。

- 選んだ機種は画面だけのもので、プリセットやチャンネルパラメータには書きません。
  残るのは、切り替えた BIT RATE・SMP.RATE・INTERP の値です
- 同じ値になる機種は「98/88」のように 1 つにまとめてあります
- 一覧にないサンプリング周波数は、近いものを選んでいます（例: X68000 の OPM の
  62.5kHz は 55.5kHz）

音源の出力が通る DAC に合わせます。

| --- | --- | --- | --- |

| MSX | 9-bit | 49.7kHz | ZOH |
| FC/GB | 4-bit | 96kHz | ZOH |
| SFC | 16-bit | 32kHz | ZOH |
| PCE | 5-bit | 96kHz | ZOH |
| MD/TOWNS | 9-bit | 55.5kHz | ZOH |

## 2686VFX: ノイズリダクションを足しました

音源の QUALITY(PCM) にあるノイズリダクションを、2686VFX でも使えるようにしました。

- 新しい効果 **[ノイズリダクション](/2686V_2686VFX/fx/noise-reduction/)** —
  QUALITY(PCM) の **GATE**（小さい音を 0 まで絞る）と **LPF**（高域カット）です。
  LPF がどこで切るかは **RATE** で決めます。PCMビットクラッシャーの後ろに
  並べ、同じ RATE を選ぶと、音源と同じ掛かり方になります
- **[PCMビットクラッシャー](/2686V_2686VFX/fx/pcm-bitcrusher/)** に **NR: Resample** —
  間引く前に高域を切って、折り返しを防ぎます。間引きと一緒でないと意味が
  ないので、こちらはビットクラッシャーの中に置きました

どれも既定は切れていて（ノイズリダクションはバイパス）、これまでの音は
変わりません。ノイズリダクションは効果の順番の最後に足されます。

## ファイルを画面へドラッグ＆ドロップして読み込めるようにしました

エクスプローラーなどからファイルを画面へ落とすと、そのまま読み込みます。
読み込んだあとは、それぞれを読み込みボタンから読んだときと同じに振る舞います。

| ファイル | 読み込んだあと |
| --- | --- |
| プリセット | そのチャンネルのタブを開く |
| チャンネルパラメータ | そのチャンネルのタブを開く |
| FX の順番（`.fxo`） | FX の並びが変わる |
| FX のパラメータ（`.2fx`） | FX の値が変わる |

2686VFX では FX の順番とパラメータを受け付けます。画面は切り替わりません。
複数のファイルを一度に落としたときは、並びのとおりに読み込みます。

## 相対パスの基準を選べるようにしました

プリセットとチャンネルパラメータに書く音声・波形ファイルの場所は、これまで
設定の置き場（`Samples` / `Wavetable`）からの相対で決まっていました。3.6.3 では、
基準を次の 2 つから選べます。

| 選択 | 基準 |
| --- | --- |
| 指定のディレクトリ | 設定の置き場（これまでどおり。初期値） |
| ファイルのディレクトリ | 読み書きしているプリセット・チャンネルパラメータの置き場 |

- 選ぶのは、OPZX7 / RHYTHM / PCM（ADPCM）/ PCM+（ADPCM+）/ WT / WT2 / WT+ の
  UTILITY と、SETTINGS のフォルダ設定の先頭にある **REL.PATH** です。値は
  プラグイン全体で 1 つで、どこで変えても同じです
- 環境設定のファイルにも保存します（SETTINGS で保存したとき）
- 「ファイルのディレクトリ」を選ぶと、チャンネルパラメータも、そのファイルからの
  相対で場所を書きます。プリセットや音色と素材を 1 つのフォルダにまとめて、
  フォルダごと持ち運べます
- 読むときは、選んでいない側の基準も試します。どちらの設定で書いたファイルも
  読めます
- DAW のプロジェクトへの保存は、ファイルを伴わないので設定の置き場を使います

あわせて、**WT / WT2 / WT+ のチャンネルパラメータにも波形ファイルの場所を
書く**ようにしました。WT PITCH MOD・WT AMP MOD の変調波形（`waves`）と、WT+ の
枠ごとの波形（`waveFile`）です。読み込むと波形も読み直します。これより前の
ファイルには無いので、読んでも今の波形のまま残ります。
