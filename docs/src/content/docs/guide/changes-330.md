3.2.0 から 3.3.0 までの変更をまとめます。**読み込めなくなるファイルはありません。**
3.2.0 までに作ったプリセットやパラメータファイルは、そのまま読めます。

この版で足したつまみは、どれも**入っていないファイルを読んでも今までどおり
鳴る**ようにしてあります。値そのものから「使う・使わない」を推し量ると、
初期値を指定できなくなるうえ、切り替わる条件が画面から見えません。入り切りの
札を対で置き、切のあいだはこれまでと同じ経路を通します。

## ADPCM+ チャンネルを足しました

**音声ファイルを 32 本読み込んでおいて、演奏しながら切り替える**チャンネル
です。[WT+](/2686V_2686VFX/chips/wtplus/) が波形メモリに対してしていることを、
そのまま PCM へ移したものです。

ADPCM と大きく違うのは、**音の作り方が素材ごとに分かれている**ところです。
FORM・OPTIONAL・PAN は PCM 1 本ごとに値を持つので、素材を切り替えると
鳴らし方も一緒に切り替わります。

- **SLOT** が鳴らす PCM です。オートメーションで切り替えられます
- **TARGET** が画面へ出す PCM です。音には効きません。鳴らしているものとは
  別の PCM を、鳴らしたまま編集できます
- 読み込んだ 32 本は**並べて表示**します。枠が付いているものが TARGET、下地に
  色が敷かれているものが SLOT です

入っているのは **2686V・2686VLight・PCMV** です。詳しくは
[ADPCM+ チャンネル](/2686V_2686VFX/chips/adpcmplus/) を参照してください。

:::note[タブの並びと音源の番号]
ADPCM+ は ADPCM の右へ入りましたが、**音源の番号は末尾へ足しています。**
番号は保存したファイルやオートメーションが指すので動かせないためです。
3.2.0 までに作ったものは、これまでどおりの音源で開きます。
:::

## 波形を止める・一部だけ鳴らす

**HOLD** と **KEEP** を足しました。

- **HOLD** は、決めた周回数まで鳴らしたら波形を止めます。止まったあとは
  MIN か MAX の値を出し続けます
- **KEEP** は、1 周のうち START〜END の区間だけを鳴らします。区間の外は、
  端の値をそのまま伸ばすか 0 にするかを選べます

出てくるのは、WT・WT2・WT+・SSG の OPTIONAL と、WT PITCH MOD / WT AMP MOD /
SSG HW AMP ENV / SSG HW PITCH ENV / LFO です。**もともと 1 周で止まる形**
（SSG HW ENV の 1・3・5・7 番、LFO の 6・7 番）が選ばれているときは、
二重に止めても何も起きないので押せなくなります。

止まる側を**スイッチで固定**しているのは、値が動いている途中で止めると
鳴るたびに違う音になってしまうためです。

詳しくは [HOLD / KEEP](/2686V_2686VFX/chips/common/#hold--keep--波形を止める一部だけ鳴らす)
を参照してください。

## 再生速度 (SPEED) を足しました

1 サンプルぶん進む量へ掛ける倍率です。**0.0001〜100.0**、初期値 1.0。
ノートによる速さの変化は今までどおり求めたうえで、その結果へ掛けます。

RHYTHM はノートで速さが変わらないので、SPEED がそのまま素材の速さに
なります。

対象は RHYTHM / ADPCM (PCM) / ADPCM+ / OPZX7S の WS / WT / WT2 / WT+ / SSG
です。あわせて、**WT・WT2・WT+・SSG へ OPTIONAL 区分を新しく作りました。**
この 4 つはこれまで OPTIONAL を持っていませんでした。

## ループカウンター (CNT) を足しました

ループポイントで折り返すたびに数え、決めた回数に届いたら折り返さずに先へ
進みます。**0〜3000**で、**0 は無限**（これまでどおり）です。1 音ごとに
やり直します。

対象は RHYTHM / ADPCM (PCM) / ADPCM+ / OPZX7S の WS です。

刻むボタンは 2 段になっています。上が **-10 / -1 / 0 / +1 / +10**、下が
**-1000 / -100 / +100 / +1000** です。0〜3000 は幅が広く、1 ずつでは遠く
100 ずつでは粗いので桁で分けました。0 は「無限に回す」の意味を持つので、
上の段の真ん中へ置いてあります。

## 再生遅延 (DELAY) を足しました

キーを押してから鳴り始めるまでの間です。**0.0〜60.0 秒**、初期値 0.0。
待っている間は**位相も包絡も進めません**。鳴らしてから捨てる作りだと、
待ったあとに音の途中から始まってしまうためです。

3 つの段を別々に数えます。

| 場所 | 数 |
| --- | --- |
| チャンネル全体 | 13 チャンネル |
| オペレーター | FM 6 種、2〜8 本 |
| リズムのパッド | 8 枚 |

チャンネル全体で 1 秒待ち、そのうえで OP1 だけさらに 0.5 秒待つ、といった
重ね方ができます。変調する側を先に鳴らして、あとから搬送波が入る、という
作り方に使えます。

OPTIONAL の並びは、**鳴り始め → 速さ → 繰り返し**という時間の流れに沿って
DELAY / SPEED / CNT の順にしてあります。

## エンベロープへ KEEP と ENDL を足しました

**KEEP** は、段ごとのレベルを斜めに繋がず、その段の始まりの値を段の長さぶん
保ち、段の終わりで次へ飛びます。段の長さは変わりません。対象は PITCH ENV /
SSG SW AMP ENV[11] / SSG SW PITCH ENV[11] です。

**ENDL** は、リリースを走り終えたあとに保つレベルです。対象は AMP ENV /
PITCH ENV / SSG SW AMP ENV[11] / SSG SW PITCH ENV[11] です。**USE ENDL** を
入れたときだけ効きます。切のあいだ（既定）はこれまでと同じ経路を通るので、
既存のパッチの余韻は変わりません。

## WT+ の OPTIONAL をスロットごとに持たせました

WT+ の **SPEED と HOLD / KEEP は、波形メモリのスロット 32 枚それぞれが
別の値を持ちます。** TARGET を動かすと、その枠の値へ切り替わります。

波形ごとに止め方を変えられるので、SLOT を動かすだけで鳴り方まで入れ替わり
ます。

## FM と RHYTHM のタブを、絵と設定ひとそろいにしました

OPNA / OPN / OPL / OPL3 / OPM / OPZX7S / RHYTHM のタブは、これまで
オペレーターやパッドの数だけ区分をひとそろいずつ並べていました。3.3.0 では
**上に絵、下に設定ひとそろい**という形へまとめています。

<figure class="shot">
	<img src="/2686V_2686VFX/ui/channel/ch_opna.png" alt="OPNAチャンネル" style="width:600px;" />
	<figcaption>OPNA チャンネル。上が絵、下が TARGET と設定</figcaption>
</figure>

- **上の枠** — オペレーター（パッド）ごとのエンベロープの絵を、横 4 枚ずつ
  並べます。OPZX7S は WAVE SHAPE の波形を、RHYTHM は読み込んだ音声の波形を
  一緒に出します。**枠のどこを押しても、そこへ TARGET が移ります**
- **TARGET** — 下の設定がどのオペレーター（パッド）を指しているかです。
  指している枠は線で囲います。帯は「TARGET → 指しているものの名前 →
  AMP / PIT / SSG / S11 / P11」の順に並びます。右の札は、上の絵に**どの
  エンベロープを映すかを、全部の枠まとめて**切り替えます
- **設定** — 区分を横へ 1 列ずつ並べ、あふれたぶんは下の送り棒で送ります。
  最初から開いた状態です。縦に短い区分は、いくつかを 1 列へまとめてあります
- **TARGET は画面を閉じても覚えています**
- **Ctrl + ← / →** で TARGET をひとつずつ、**Ctrl + 数字**でその番号へ移せます。
  WT+ と ADPCM+ のスロットも **Ctrl + ← / →** で動きます
  （[ショートカットキー](/2686V_2686VFX/reference/shortcuts/)）

オペレーターを 4 つずつ並べるのをやめたので、OPZX7S の **VIEW MODE**
（上下の段の切り替え）は無くしました。音やファイルには関係しません。

## 画面まわりを直しました

- **ラベルの幅を 8 文字ぶんへ広げ、綴りを戻しました。** LV → LEVEL、
  SHPE → SHAPE、P.OF → P.OFFSET のように、詰めて書いていた綴りを読める形に
  しています。FX の LGn → LOW.GAIN、FC0 → COEF0、QUALITY の INTP → INTERP、
  OPZX7S の POFF → P.OFFSET・B.P → BREAK.PT・F.OP → FB.TARGET、SSG の RAT → RATIO、
  BEEP の CLK → CLOCK も同じく戻しました。行の合計は変えていないので、置き場所は動きません
- **RHYTHM のパッドの LEVEL にも値ボタンを付けました。** N を押すと、
  チャンネルの LEVEL と同じ並び（±1.0 / ±0.1 / ±0.01、1.0、0.25 など）が出ます
- **WT+ と ADPCM+ の OPTIONAL、ADPCM+ の PAN を、最初から開いた状態に
  しました**
- **はじめて画面を開いたときに、簡易表示モードで使うかを尋ねるように
  しました。** 答えると標準設定のファイルを作るので、次からは尋ねません。
  詳しくは [初期設定の問い](/2686V_2686VFX/guide/install/#初期設定の問い) にあります
- **2686VFX の効果を、仲間どうし 1 列へ積みました。** 9 列あった効果が
  4 列になり、右の変調まで短い距離で届きます。かける順番は変わりません
- **トグルボタンの並べ方を選べるようにしました。** SETTINGS の「簡易表示
  モード」の下にあります。中央寄せ（従来）と左寄せの 2 つで、切り替えた
  その場で画面じゅうへ効きます
- **OPTIONAL の中へ区切り線を足しました。** 上は再生位置・倍率、下はループ
  の話でまとまりが変わるためです
- **ブラウザにショートカットキーを足しました。** **ESC** で閉じ、**Ctrl+M**
  でプレビューを作ります
- **一覧で同じ行をもう一度押すと、選ぶのをやめます。** ダブルクリックは
  これまでどおりです

## 直したもの

3.2.0 までにあった不具合です。

- **2686VLight・26V・86V・OPZX7S で、OP / CL と「非表示中の区分をバイパス」が
  効いていませんでした。** ボタンは出ていても、どのタブでも何も起きません
  でした。3.1.0 で足したときに、この 4 本のタブへ中身が入っていなかったためです
- **Ctrl + C で書き出す MML のマスクが、OP3・OP4 の状態を映していません
  でした。** 2 番目のオペレーターのぶんを二度並べていました。対象は OPNA /
  OPN / OPL3 / OPM です
- **OPZX7S の TARGET が 6 までしか動かず、** 7・8 番のオペレーターを
  オペレーター単位で読み書きできませんでした
- **86V の RHYTHM で、TARGET とパッドのコピー元・コピー先が 8 まで選べました。**
  86V のパッドは 6 枚なので、7・8 は無いパッドを指していました
- **SETTINGS の「設定ファイルから読み込み」で、読んだ値の一部が画面へ
  出ていませんでした。** 簡易表示モード・ツールチップ・ヘッドルーム・仮想
  MIDIキーボードのトグルが前の値のまま残り、簡易表示モードとツールチップ、
  仮想MIDIキーボードは、切り替え直すまで読んだ値が効いていませんでした

## 古い形式のファイルについて

3.0.0 より前の**行並びの形式**へは、この版で足したつまみを書いていません。
行を増やすとその形式で書かれた既存のファイルが読めなくなるためです。
読み込みはこれまでどおりできます。書き出しは名前で並べる新しい形式になり、
そこには新しいつまみも入ります。
