3.0.0 から 3.1.0 までの変更をまとめます。**読み込めなくなるファイルはありません。**
3.0.0 で作ったプリセットやパラメータファイルは、そのまま読めます。

## 足した変調

### SSG HW PITCH ENV

[SSG HW AMP ENV](/2686V_2686VFX/chips/common/#ssg-hw-amp-env) と**同じ形の波**を、
音量ではなく音程へ当てる区分です。実機のハードウェアエンベロープは音量にしか
掛かりませんでしたが、同じ形を音程へ回すと、アルペジオやトリルのような動きが
繰り返しで作れます。

- MIN / MAX は**セント**で、**−4800〜4800**（上下 4 オクターブ）
- 初期値は MIN = 0 / MAX = 1200（1 オクターブ）
- 値の増減にはピッチ系と同じ **±100 / ±1200** のボタンが付きます
- 波形は SSG HW AMP ENV と同じ 44 種
- 全チャンネル（FM を含む）・全オペレータ・RHYTHM の全パッドで使えます
- 単体ファイル（`.ssgHwPEnv`）の読み書きに対応

詳しくは [SSG HW PITCH ENV](/2686V_2686VFX/chips/common/#ssg-hw-pitch-env) を
参照してください。

### WT AMP MOD

[WT PITCH MOD](/2686V_2686VFX/chips/common/#wt-pitch-mod) と**同じ変調波形**を、
音程ではなく音量へ当てる区分です。出力は MIN〜MAX の間を動きます。

- MIN / MAX の初期値は 0.0 と 1.0。**波形スロットをまたいで 1 組だけ**持ちます
- DPTH は「MAX からどれだけ下げるか」の割合。0.0 なら音は変わりません
- 値の増減にはナッジボタンが付きます
- HuC6280 の波形メモリと FDS のユーザーテーブルにも対応
- 全チャンネル（FM を含む）・全オペレータ・RHYTHM の全パッドで使えます
- 単体ファイル（`.wtampmod`）の読み書きに対応

詳しくは [WT AMP MOD](/2686V_2686VFX/chips/common/#wt-amp-mod) を参照してください。

### FDS TABLE の名前が 2 つに分かれました

WT PITCH MOD のテーブルは **FDS PITCH TABLE**、WT AMP MOD のテーブルは
**FDS AMP TABLE** になりました。中身の意味は変わりません。**それぞれ別に
持てます。**

## オペレータでも使えるようになったもの

これまでチップ全体にしか無かった 2 つを、FM のオペレータごとにも持たせました。

- SSG HW AMP ENV
- WT PITCH MOD

チップ全体のものとは**別のパラメータ**なので、OPNA や OPZX7S では従来の
SSG HW ENV と共存し、両方を同時に掛けられます。WT PITCH MOD の変調波形スロットも
オペレータごとに別々です。

オペレータのパラメータファイルにも収まるので、[IM] / [EX] からオペレータ単位で
読み書きできます。

## 2686VFX

出力への変調に **WT AMP MOD**（音量側）と **SSG HW PITCH ENV**（音程側）を
足しました。中身は音源のものと同じです。

WT AMP MOD の速さも搬送波との比なので、WT PITCH MOD と**同じ基準周波数**を使います。

## 画面

### 区分の色分けを細かくしました

ソフトウェア由来の区分が水色ひと色だったので、役割ごとに色相を分けました。
ハードウェア由来（黄）・音質（赤）・その他（黄緑）は従来のままです。

| 色 | 区分 |
| --- | --- |
| 青 | AMP ENV / SSG SW AMP ENV / SSG SW AMP ENV[11] / WT AMP MOD / FDS AMP TABLE |
| ターコイズ | PITCH ENV / SSG SW PITCH ENV[11] / WT PITCH MOD / FDS PITCH TABLE |
| 紫 | LFO |
| シアン | OPTIONAL / UNISON・HARMONY / FIX / MUL・DET（従来通り） |

SSG HW AMP ENV と SSG HW PITCH ENV、WT PITCH MOD と WT AMP MOD は、自分の
チャンネル（SSG / WT / WT2 / WT+）では従来どおり**黄色**のままです。他の
チャンネルへ借りて置くときだけ上の色になります。

### 2686VFX の枠も系統ごとに塗り分けました

| 系統 | 色 |
| --- | --- |
| 効果（PCM ビットクラッシャーを含む） | 青系統（従来通り） |
| 出力への変調 | 赤系統 |
| LFO | 緑系統 |
| MUL・DET / UNISON・HARMONY | シアン系統 |

### 簡易表示モードを足しました

区分が増えて 1 つのタブが縦に長くなったので、**よく使うものだけ残して畳む**
切り替えを SETTINGS へ置きました。「ツールチップを表示」の上にあります。
初期状態は OFF です。

**出しているものを隠すだけで、音は変わりません。** 隠した区分の値もそのまま
残ります。

何を隠すかはタブごとに決めてあり、**そのチャンネルが実機の機能として持って
いる区分は残します。** SSG では SSG HW AMP ENV が、WT / WT2 / WT+ では
WT PITCH MOD が残ります。2686VFX では変調の枠が隠れ、効果の枠は残ります。

スイッチを入れると下に **簡易表示モードカスタマイズ** が出ます (初期状態は
閉じています)。ここで入れた区分は簡易表示モードでも隠れません。対象は
AMP ENV / SSG HW AMP ENV / SSG SW AMP ENV / SSG SW AMP ENV[11] / WT AMP MOD /
PITCH ENV / SSG HW PITCH ENV / SSG SW PITCH ENV[11] / WT PITCH MOD / LFO /
MUL・DET / FIX / UNISON・HARMONY の 13 区分です。

設定は他の項目と同じく設定ファイルへ保存されます。

### 区分をまとめて切る・開閉するボタンを足しました

隠れているのは表示だけで音は残ったままなので、まとめて切れるようにしました。

- **[非表示中の区分をバイパス]** — SETTINGS の「簡易表示モード」の右隣。
  いま隠れている区分だけを切ります。簡易表示モードが切ってあるあいだは
  押せません。
- **[OP]** — 切っていない区分をまとめて開きます。画面右上、表示モードの左。
- **[CL]** — 切ってある区分をまとめて閉じます。同じ場所。

OP / CL は**全チャンネル・全オペレータ・全パッドに一度で効きます。** どの
ボタンも、入り切りの札を持たない MUL・DET と UNISON・HARMONY は触りません。
LFO は PM と AM の両方をまとめて扱います。

### 区分の並び順を整えました

区分が増えて並びが場当たりになっていたので、系統ごとにまとめ直しました。
**ハードウェア由来のものとソフトウェア由来のものが両方あるところでは、
ハードウェア由来を上に置きます。**

| ところ | 並び |
| --- | --- |
| FM のチップ全体 | ALGORITHM/FEEDBACK → AMP ENV → 音量系 → ピッチ系 → LFO → PAN → UNISON/HARMONY → QUALITY → MIDI → UTILITY |
| FM のオペレータ | AMP ENV → OPTIONAL → WAVE SHAPE → 音量系 → ピッチ系 → KEY SCALE → MUL/DET → LFO → FIX → MASK |
| SSG / ADPCM / BEEP / RHYTHM パッド | FORM → OPTIONAL → 音量系 → ピッチ系 → LFO → MUL/DET → FIX → UNISON/HARMONY → QUALITY → MIDI → UTILITY |
| WT / WT2 / WT+ | 同じ並び。ただし変調が実機の機能なので、音量系・ピッチ系の先頭が WT AMP MOD / WT PITCH MOD になります |

音量系の内訳は SSG HW AMP ENV → SSG SW AMP ENV → SSG SW AMP ENV[11] →
WT AMP MOD、ピッチ系は PITCH ENV → SSG HW PITCH ENV → SSG SW PITCH ENV[11] →
WT PITCH MOD です。

### 画面が開くまでを短くしました

区分が増えて、1 つのタブが数百の部品を抱えるようになりました。これまでは
画面を開いた時点で全部のタブを作っていたので、開くまで待たされていました。

**開いているタブだけを作り、他のタブはそこへ切り替えたときに作る**ように
しました。見た目も操作も変わりません。切り替えた先のタブは、そのとき初めて
作られるので、一度目だけ少し間があきます。二度目からはそのままです。

「非表示中の区分をバイパス」は、見ていないタブのパラメータも切らないと
意味がないので、押したときに全部のタブを作ります。OP / CL は見た目だけの
操作なので、後から開いたタブにも同じ形で反映します。

### PCM ビットクラッシャーを FX のパラメータファイルへ入れました

2686VFX にしかない PCM ビットクラッシャーだけが、FX のパラメータファイル
(`.2fx`) に書かれていませんでした。順番のファイルには入っていたので、
並びは残せても設定は残せない状態でした。`pcmBitCrusher` のまとまりを足して
います。

3.1.0 より前に書いたファイルにはこのまとまりがありませんが、そのときは
今の値をそのまま使うので読めなくなることはありません。音源で読んだときは、
このまとまりを見に行かないので飛ばされます。

## 直したところ

- RHYTHM のパッドで、サンプリング周波数を変えても SSG HW AMP ENV へ伝わって
  いませんでした
- RHYTHM のパッドのパラメータファイルに WT PITCH MOD が入っていませんでした
