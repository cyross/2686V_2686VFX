3.1.0 から 3.2.0 までの変更をまとめます。**読み込めなくなるファイルはありません。**
3.1.0 までに作ったプリセットやパラメータファイルは、そのまま読めます。

## つまみの刻みを細かくしました

実数のつまみが、これまで **0.01 きざみ**になっていました。土台にしている
juce の既定がその刻みだったためで、こちらで指定していたわけではありません。
たとえば包絡の時間を 0.0035 秒にしたくても、0.00 か 0.01 にしかできません
でした。

**0.0001 きざみ**に直しました。表示も、末尾に並ぶ 0 を落とすようにしてある
ので、`0.5` は `0.5000` ではなく `0.5` のまま出ます。

これまでのファイルは 0.01 の倍数で書かれているだけなので、読んでも値は
変わりません。

## ファイルを選ぶ画面を作り直しました

これまでは OS のファイル選択ダイアログを開いていました。区分の見分けが
つかず、中身を確かめるには一度読み込むしかありませんでした。

**画面をほぼ覆う一覧**に置き換えています。

- **キーワード・区分・ファイル形式で絞り込めます**。キーワードを打っている
  間だけは、下のフォルダまで潜って探します
- **見出しを押すと並べ替わります**。押すたびに「並べ替えなし → 昇順 →
  降順」と回ります
- **フォルダを辿れます**。一番上の「上へ」で親フォルダへ戻り、フォルダの
  作成と削除もできます
- **波形のプレビューが出ます**。パラメータファイルはその設定で実際に
  鳴らした波形、波形ファイルと音の素材は中身をそのまま描いた止め絵です
- **外を押すと、選ばずに閉じます**

行は選ぶのも開くのも**ダブルクリック**です。フォルダも同じで、一度押すと
選ばれ、二度押すと中へ入ります。

パラメータ・プリセット・波形は、**このプラグインの置き場より上のフォルダ
へは行けません**。外へ出ても、選べないファイルばかりが並ぶためです。音の
素材 (wav) だけは、どこから持ってきても構わないので縛っていません。

## プリセットをチャンネルで絞れるようにしました

プリセットは音源をまるごと差し替えるものなので、たいていは目当ての音源の
ものだけを見たいはずです。PRESET タブの検索欄と一覧の間に、**チャンネルで
絞る行**を足しました。

チャンネルの数だけチェックを並べると横に伸びて検索欄を押し出してしまうので、
**対象を選ぶコンボと、その入り切りのチェック**の 2 つに畳んであります。いま
入れているものは、その右に並べて出します。

- **入れたものだけが出ます。ひとつも入れていなければ絞りません**
- **すべて ON / すべて OFF** で、まとめて切り替えられます
- 選択肢に並ぶのは、そのプラグインが積んでいる音源だけです

はじめの状態はプラグインによって変わります。**音源を絞ったプラグインは、
積んでいる音源を最初から入れてあります**。2686V と 2686VLight は 13 種すべてを
積んでいるので、初めから絞っていると却って探しにくく、すべて切ってあります。

| プラグイン | はじめから入っているチャンネル |
| --- | --- |
| 2686V / 2686VLight | (なし) |
| 26V | OPN / SSG |
| 86V | OPNA / SSG / RHYTHM / PCM |
| OPZX7S | OPZX7S |
| OPNV | OPNA / OPN |
| OPLV | OPL / OPL3 |
| OPMV | OPM |
| WTV | WT / WT2 / WT+ |
| PCMV | RHYTHM / PCM |
| PULSEV | SSG / BEEP |

## 生成波形のプレビューを足しました

チャンネルの設定から、**実際に鳴らした波形**を作って見せます。

- 作るのは**ボタンを押したときだけ**です。演奏中に作り続けることはしません
- 長さは **10 秒まで**で、途中で**鳴り終われば、そこから 0.5 秒で打ち切り**
  ます。短い音を 10 秒ぶん作っても、頭の一瞬だけ動いて、あとは止まった線が
  続くだけになるためです
- **L / M / R の 3 段**で出します。チャンネルはステレオにもパンにもできる
  ので、真ん中だけでは分かりません
- 1 / 2 / 5 / 10 周期から選べます。窓の頭は周期に合わせてあるので、波形が
  横へ流れていきません
- 作ったものはファイルへ貯めるので、次に開いたときは作り直しません。
  貯めたものは SETTINGS の**「プレビュー波形の全削除」**で消せます

## 待ち時間の見せ方を変えました

時間の掛かる処理の間、**半透明の黒の上に棒が波打つ絵**を出すようにしま
した。長く掛かるものには**中止**も付いています。

## 画面が開くまでを短くしました

2686V を Release で開くと、**34.5 秒**掛かっていました。同梱のプリセットが
1,990 件あり、一覧に出す名前や区分を集めるために、毎回すべての中身を
読んでいたのが原因です。

**索引をファイルへ持つ**ようにして、中身の読み直しは画面が出たあとに後ろで
進めます。**1.1 秒**で開くようになりました。

索引は、プリセットを足したり消したりすると作り直されます。作り直している
間は、進み具合が出て、中止もできます。

## SSG のソフトウェアエンベロープを増やしました

FMP / FMP7 / PMD の MML から、SSG のソフトウェアエンベロープを取り込んで
います。同梱のパラメータファイルとして入ります。
