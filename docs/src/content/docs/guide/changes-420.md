4.1.0 から 4.2.0 までの変更をまとめます。4.2.0 は、スライダーの値の**動かし方**を増やした版です。
全プラグイン（2686VFX を含む）が対象です。

## ラベルのドラッグで値を動かせるようにしました

スライダーの左にある名前（ラベル）を押したまま**上下へドラッグ**すると、値が動きます。
上へで増え、下へで減ります。ラベルにマウスを乗せると、上下の矢印のカーソルになります。

- 200 px で範囲の端から端まで動きます
- **STEPS** で刻みを選んでいるスライダーは、その刻みごとに動きます。0.0〜1.0 で 1/4 刻みなら、50 px で 1 刻みです
- N88-BASIC(86) の向きで見せている AR / DR / SR / RR / SL / TL も、上へで画面の数字が増えます
- STEPS を使っていないときは、キーを押しながらドラッグすると、値が刻みへそろいます

| キー | そろえる刻み |
| --- | --- |
| **Shift** | 0.1（実数のスライダーだけ。整数のスライダーでは何もしない） |
| **Ctrl** | 1 |
| **Ctrl + Shift** | 10 |

刻みの数で動くので、刻みが粗いほど 1 刻みに長い距離を使います。ドラッグの途中でキーを変えると、
その位置から数え直します。

## すべてのスライダーに N ボタンを付けました

スライダーの右端に、橙色の小さな **N** ボタンを置きました。押すと、スライダーのすぐ下に
値を動かすボタンの並びが重なって出ます（下に場所が無ければ上に出ます）。

| ボタン | 動き |
| --- | --- |
| **MIN** | いちばん小さい値へ |
| **-10** / **-1** など | その幅だけ引く |
| **DEF** | 初期値へ戻す（パラメータに束ねていないスライダーは **0**） |
| **+1** / **+10** など | その幅だけ足す |
| **MAX** | いちばん大きい値へ |

足し引きする幅は、範囲と刻みから決めます。範囲の半分までの 10 の累乗を、大きいほうから
3 つまで出します。

| 範囲 | 出るボタン |
| --- | --- |
| 0〜7 | ±1 |
| 0〜127 | ±1・±10 |
| 0.0〜1.0 | ±0.001・±0.01・±0.1 |

**STEPS** で刻みを選んでいるあいだは、刻みの倍数で動かします（1/4 刻みなら ±1/4、
1/100 刻みなら ±1/100・±10/100）。半端な幅で動かすと、丸めで元の値へ戻されてしまうためです。

並びは、並びの外を押すか、ホイールを回すと閉じます。もう一度 **N** を押しても閉じます。
スライダーそのものやラベルを触っているあいだは閉じないので、帯のドラッグと組み合わせられます。

- **カーブ編集（ADV）の K と値のスライダーにも付きます**。K の並びには、初期値の **1** へ戻すボタンもあります
- LEVEL や FIX の FREQ のように、もとから N ボタンと値を動かす行を持っているスライダーは、
  これまでどおりそちらを使います（スライダーの中には N を出しません）
- 幅が狭く、N ボタンを置くと帯が残らないスライダーには出しません

ナッジのボタンは、**押しているあいだ地の色が濃くなります**。N ボタンは、並びを出しているあいだ
濃いままです。もとからある値を動かすボタンの行（LEVEL・FIX など）と、その N ボタンも同じです。

COLORS タブには、N ボタン（`Slider.Nudge.Toggle`）、初期値へ戻すボタン（`Slider.Nudge.Reset`）、
並びの地と縁（`Slider.Nudge.PopupBg` / `Slider.Nudge.PopupBorder`）の色を足しました。

## ALG ENV の ALG の N ボタンを直しました

FM 音源の ALG ENV で、ALG の N ボタンを押しても値を動かすボタンが出ませんでした。ALG ENV だけ、
N ボタンで出すボタンの行を持っていなかったためです。

**-1** / **+1** と、アルゴリズムの番号を直に置くボタン（OPN・OPM などは 0〜7）を出すようにしました。
アルゴリズムが 130 個ある OPZX7 は、-10 / -1 / 0 / +1 / +10 / 129 です。
