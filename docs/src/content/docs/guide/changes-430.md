4.2.0 から 4.3.0 までの変更をまとめます。4.3.0 は、実機の**出力の癖**をなぞる機能を足し、
TAP SEQUENCER と 256 段のエンベロープで**動かせるパラメータを広げた**版です。

## QUALITY に「CHIP DAC」を足しました

FM 音源（OPNA・OPN・OPL・OPL3・OPM）と SSG の QUALITY に、**CHIP DAC** のトグルを足しました。
INTERP の下にあります。入れると、その音源の実機が音を出すときに通る DAC の癖をなぞります。

**初期値は切**です。切っているあいだはこれまでと同じ音で、これまでのプリセットや DAW の
プロジェクトの音は変わりません。

### FM 音源

鳴っている音をすべて足してから、実機の DAC へ通します。

| 音源 | DAC | すること |
| --- | --- | --- |
| OPN (YM2203) | YM3014B | 浮動小数点（仮数 10bit + 指数 3bit）。大きい音ほど下の桁が落ちる |
| OPM (YM2151) | YM3012 | 同上 |
| OPL (YM3526) | YM3014B | 同上 |
| OPNA (YM2608) | — | 16bit の刻みへ寄せる |
| OPL3 (YMF262) | YAC512 | 16bit の刻みへ寄せる |

- どれも 16bit を超えたぶんは頭打ちになります。実機と同じく、音を重ねすぎると割れます
- 1 キャリアをベロシティ 127・LEVEL 1.0 で鳴らした大きさを、実機の 1 チャンネルの最大に
  合わせています（OPN・OPM・OPL3 は 14bit、OPNA・OPL は 13bit）

### SSG

音量を、実機（YM2149 互換）の対数の表で鳴らします。エンベロープの値を 16 段の音量
レジスタと見なし、SSG HW AMP ENV は 32 段で表を引きます。値が下がると、これまで（線形）
より早く小さくなります。

DUTY の More Real FC / More Real NES を入れているときは、2A03 の DAC を通すので効きません。

### 保存

チャンネルパラメータ・区分のパラメータファイル（QUALITY）・プリセット・DAW の状態に
保存します（`chipDac`）。持たない古いファイルを読んでも、いまの値のままです。

詳しくは [チャンネル共通の CHIP DAC](/2686V_2686VFX/chips/common/#chip-dac--実機の-dac-を通す) を
見てください。

対象: 2686V・2686VLight・26V・86V・OPNV・OPLV・OPMV・PULSEV

## FM 音源のオペレーターの列の並びを変えました

KEY SCALE / MUL/DET の列（FIX や LFO を含む列）を、**AMP ENV / OPTIONAL の列のすぐ右**へ移しました。
音色を作るときに一緒に触ることが多いためです。OPZX7 は WAVEFORM の列より左に来ます。

OPNA / OPN / OPL / OPL3 / OPM / OPZX7 のタブで、FM 音源を持つ全プラグインが対象です。

## RHYTHM のパッドの列の並びを変えました

パッドの設定の列を、FM 音源のオペレーターと同じ形に並べ直しました。

- **MUL/DET と FIX** を OPTIONAL の下（同じ列）へ移しました。列の名前は「OPTIONAL / MUL/DET / FIX」です
- その右に、パッドの **PARAM ENV** の列（下の PARAM ENV[256] を参照）と **TAP PARAM SEQUENCER** の列を置きました
- パッドの **EDIT** は OPTIONAL の下から外し、区分の並びの一番右の「EDIT」の列へ移しました

並びは FORM / PAN / QUALITY → OPTIONAL / MUL/DET / FIX → PARAM ENV → TAP PARAM SEQUENCER → AMP ENV → … → LFO → EDIT です。
RHYTHM を持つプラグイン（2686V・2686VLight・86V・PCMV）が対象です。

## 横に並べた枠の幅を畳めるようにしました

枠の名前（見出し）をクリックすると、枠の幅が **30px** になります。見出しは灰色の帯になって縦書きで出て、中身は隠れます。
もう一度クリックすると元の幅に戻ります。使わない枠を畳んでおけば、横に送らずに見渡せる範囲が広がります。

- 全て開く **<>** と、全て閉じる **><** のボタンを足しました。FM 音源と RHYTHM はオペレーター・パッドのグラフの切り替え（AMP / PIT / S256 / P256 / PRM）の右、2686VFX は画面上の CPHIST の左に、少し空けて置いてあります。**<>** は濃い緑、**><** は濃い青の地にオフホワイトの文字です
- どの枠を畳んだかは、プリセットと DAW の状態に保存します。2686VFX はプリセットを持たないので、DAW の状態だけです。4.3.0 より前のプリセットは、すべて開いた状態で読みます
- 2686VFX の効果は 1 列に 2〜3 枠を積んでいます。列の幅が 30px になるのは、その列の枠をみな畳んだときです。メインの枠は畳みません

FM 音源のオペレーターの列（OPNA / OPN / OPL / OPL3 / OPM / OPZX7）、RHYTHM のパッドの列、2686VFX の効果と変調の枠が対象です。

## マウスが乗っているものの色が変わります

いまどこを触ろうとしているかが見て分かるようにしました。すべてのプラグイン（2686VFX も）が対象です。

- クリックで開閉できる区分の見出しと、畳める枠の見出し（畳んだ枠の縦の帯も）は、マウスが乗っているあいだピンク寄りの色になります
- マウスが乗っている区分は、中身の背後の板が少し明るくなります。大区分の中では、乗っている小区分だけが明るくなります
- テキストボタン・コンボボックス・トグルボタン・スライダー・テキストエディタは、マウスが乗っているあいだ地と枠の色が変わります。
  変わり方は元の色によります（暗い色は明るく、明るい色は少し暗く、透けている色は少し濃く）。トグルボタンは四角の枠と中のランプ、
  スライダーは帯と値の枠が変わります

## スライダーのドラッグに Alt を足しました

ラベルのドラッグと、グラフの拡大率のつまみのドラッグで、**Alt** を押しているあいだ値が **100 刻み**へ
そろいます。範囲が 100 より狭いスライダーでは何もしません。全プラグイン（2686VFX を含む）が対象です。

| キー | そろえる刻み |
| --- | --- |
| **Shift** | 0.1（実数のスライダーだけ） |
| **Ctrl** | 1 |
| **Ctrl + Shift** | 10 |
| **Alt** | 100（4.3.0 から） |

## TAP PARAM SEQUENCER を足しました

[[TAP SEQUENCER]] に 3 つ目の区分 **TAP PARAM SEQUENCER** を足しました。鍵を押すたびに段を 1 つ進め、
その段に入れた **(パラメータ, 値) の組**で、パラメータを**その音のあいだ**置き換えます。独自拡張として、
1 つの段に組を**最大 16 個**入れられます。

チャンネルに 1 つ（[[TAP SEQUENCER]] の中）と、FM 音源のオペレーターごと・RHYTHM のパッドごとに 1 つずつ
（オペレーター・パッドの設定の列）あります。並ぶのは持ち主のパラメータだけで、どれも打鍵ごとに別々に段を進めます。

選べるのは次のものです。オン / オフのトグルは選べません。

- FM 音源のオペレーターの数値のパラメータ（TL / AR / DR / SR / SL / RR / KS / MUL / DT など）と FIX の周波数
- FM 音源のチャンネルの ALG / FB
- WT PITCH MOD / WT AMP MOD の波形と速さ
- WT+ の波形、ADPCM+ の音声（スロット）
- SSG のデューティ比と三角波の頂点
- FIX の周波数、各種の周波数・速さ（LFO・SSG HW ENV の周期・ノイズ・SPEED・TIMER CLOCK・ARP FREQ など）

段の進め方（LOOP・SKIP・INCREMENT / DECREMENT / CLEAR STEP・打鍵 1 回につき 1 段）は TAP AMP / PITCH SEQUENCER と
同じです。くわしくは [TAP PARAM SEQUENCER](/2686V_2686VFX/chips/common/#tap-param-sequencer) を参照してください。

## PARAM ENV[256] を足しました（TL ENV はこの機能にまとめました）

SSG SW AMP ENV[256] と同じ 256 段のエンベロープで、**TARGET** で選んだパラメータを動かす **PARAM ENV[256]** を
足しました。選べるパラメータは TAP PARAM SEQUENCER と同じです。

- チャンネルに 1 本（新しい大区分 **[[PARAM ENV]]**。[[TAP SEQUENCER]] の上）
- FM 音源はオペレーターごとにも 1 本（設定の列「PARAM ENV」。KEY SCALE / MUL/DET / FIX の右に、独立した列で置きます）
- RHYTHM はパッドごとにも 1 本（設定の列「PARAM ENV」。OPTIONAL / MUL/DET / FIX の右）。並ぶのはそのパッドのパラメータです
- 値は指し先のパラメータの範囲の割合で持ち、画面には指し先の書き方で出します
- 値（STL・L・LR・ENDL）は TARGET ごとに別に持ちます。TARGET を変えると、その指し先の値に切り替わります
- 整数や選択肢のパラメータは、段のあいだ値を保ちます
- MUL・DT・FIX の FREQ など押したときに決まるパラメータも、鳴っているあいだ段ごとに変わります
- STEP が 1 のときは R.TARGET を動かせません（ほかの段のエンベロープ・TAP SEQUENCER の S.TARGET なども同じ）

**FM 音源のオペレーターの TL ENV は、PARAM ENV の指し先 TL になりました。** 4.2.x までのプリセット・DAW の状態・
チャンネルパラメータ・区分のパラメータファイル（`.tlEnv`）は、読み込むときに PARAM ENV（TARGET が TL）へ写すので、
同じように鳴ります。パラメータの ID は `_TLENV_*` から `_PRMENV_*` に変わったため、DAW で TL ENV を
オートメーションしていたときは割り当て直してください。ただし STL・段の値・LR・ENDL は TARGET ごとに値を
持つようにしたためパラメータではなくなり、オートメーションでは動かせません（割り当て直す先もありません）。

くわしくは [PARAM ENV\[256\]](/2686V_2686VFX/chips/common/#param-env256) を参照してください。

## グラフに、鳴っている位置を動かして出せるようにしました

鍵を弾くのに合わせて、TAP SEQUENCER のいまの段の印と、エンベロープの鳴っている位置（グラフの上の黄色の縦線）を
動かします。縦線は PARAM ENV[256]（PRM）と、AMP ENV・PITCH ENV・SSG SW AMP / PITCH ENV[256]・FM 音源のオペレーターの EG
（AMP / PIT / S256 / P256）に出ます。SETTINGS で「TAP SEQUENCER」「PARAM ENV」「そのほかのエンベロープ」を別々に入り切りでき、
速さを 15 / 30 / 60 / 120 FPS から選べます（初期値は入・30 FPS）。

チャンネルのグラフ、FM 音源のオペレーターのグラフ、RHYTHM のパッドのグラフの切り替えに **PRM**（PARAM ENV[256]）を足しました。
くわしくは [グラフの鳴っている位置](/2686V_2686VFX/guide/screen/#グラフの鳴っている位置) を参照してください。

## 段のエンベロープに STRICT R を足しました

段は「行き先の値に着いたとき」に終えるので、前の段と同じ値の段は R 秒を待たずに終わり、その後の段が早く来ます
（KEEP のときも同じ）。リリースも、最後の段と LR が同じ値なら RR を待たずに ENDL へ移ります。
KEEP の下の **STRICT R** を入れると、段は R 秒、リリースは RR 秒たったところで終えます。SSG SW AMP / PITCH ENV[256]・
PARAM ENV[256]・ALG ENV・DUTY RATIO ENVELOPE・PEAK RATIO ENVELOPE の区分ごとに持ちます。

初期値は切なので、これまでのパッチの鳴り方は変わりません。

## グラフのサスティンの区間を見分けられるようにしました

AMP ENV / PITCH ENV / SSG SW AMP ENV[256] / SSG SW PITCH ENV[256] / PARAM ENV[256] のグラフで、鍵を押しているあいだ保つ
区間（サスティン）を、決まった幅・別の色（黄緑）で描きます。

- 段のエンベロープ（SSG SW AMP / PITCH ENV[256]・PARAM ENV[256]）にも、最後の段を走り終えて保つ区間を足しました。
  これまでは最後の段のすぐ後にリリースを描いていました
- KEEP のとき（PARAM ENV の整数・選択肢の指し先は常に KEEP）も、リリースの終わりで LR（Use Endl なら ENDL）へ移る線を
  描くようにしました

## 区分の見出しの色を変えました

- TAP AMP SEQUENCER はシアン、TAP PITCH SEQUENCER は白寄りの紫にしました（これまでと逆の組み合わせです）
- PARAM ENV[256] と TAP PARAM SEQUENCER は白寄りのダークブルーにしました

## マニュアルに「チュートリアル」の章を足しました

音を作りながら操作を覚えるページを、これから足していきます。動画や動く絵も貼れます。

## SSG に実機の鳴り方を足しました

- 矩形波の設定に **More Real SSG** を足しました。SSG（YM2203 / YM2608B）の鳴り方（デューティ比 50% 固定・単極・
  直流カット・対数の音量・トーンとノイズの論理積）を真似ます。FC Mode / More Real FC / More Real NES とは排他です
- 三角波の設定に **More Real FC** を足しました。FC の 4bit × 32 段の階段の三角波を真似ます
- 矩形波・三角波のグループの下半分を **NOISE** グループにし、**More Real FC**（FC の 15bit LFSR のノイズ）を置きました

どれも初期値は切で、これまでの音は変わりません。くわしくは [SSG](/2686V_2686VFX/chips/ssg/) を参照してください。

## DUTY / PEAK RATIO ENVELOPE に STEPS を足しました

値のつまみの下の **STEPS** で、値を 1/10・1/4・1/5・1/8・1/16 の刻みへ丸められます。DUTY RATIO ENVELOPE は
10% / 25% / 20% / 12.5% / 6.25%、PEAK RATIO ENVELOPE は 0.1 / 0.25 / 0.2 / 0.125 / 0.0625 単位です。

## 簡易表示モードで隠すものを足しました

PARAM ENV[256] と TAP PARAM SEQUENCER は、簡易表示モードで隠れます。SETTINGS の**簡易表示モードカスタマイズ**に
「PARAM ENV[256]」と「TAP PARAM SEQUENCER」を足したので、出したままにもできます。**[非表示中の区分をバイパス]** でも
切れます。

## ADPCM+ のスロットをすべて符号化しておくようにしました

TAP PARAM SEQUENCER / PARAM ENV で ADPCM+ の VOICE を変えると、選んでいないスロットも鳴ります。そのため、
読み込んであるスロットは QUALITY を変えたときにすべて符号化し直すようにしました。

## 機種名・部品名を略記で書くようにしました

画面の文字とマニュアルの機種名・部品名を、FC・PCE・MD・98・88・X68K・26・86 などの略記にしました。
COLORS タブの実機のパレット、QUALITY の機種選び（MSX は 2413 と TR に分けました）、WT PITCH / AMP MOD の
「7: PCE Wave」、QUALITY(PCM) の BIT の「15: SFC BRR」「19: Z280」「20: K53」「21: K54」、BEEP の TIMER CLOCK の「2: PCAT」などが変わります。

名前だけの変更です。音・パラメータの ID・保存の形は変わらないので、これまでのプリセットや DAW の状態はそのまま読めます。
