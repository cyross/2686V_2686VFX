3.6.0 から 3.6.1 までの変更をまとめます。**読み込めなくなるファイルはありません。**
パラメータも増減していないので、開いただけで音が変わることもありません。

## 読み込んだ波形が、プロジェクトを開き直すと戻らなかったのを直しました

**WT+ に読み込んだ波形が、プロジェクトを保存して開き直すと入っていないことが
ありました。** FL Studio で見つかったものですが、どの DAW でも、スタンドアロンでも
起きます。

波形ファイルの場所は、SETTINGS の「波形フォルダ」からの相対パスで保存しています。
ところが、波形を読み込むたびに、その「波形フォルダ」が**読み込んだファイルの
フォルダへ書き換わっていました**。そのため、波形フォルダの下のフォルダから読んだ
波形は、ファイル名だけで保存されます。プラグインを立ち上げ直すと波形フォルダは
設定の値へ戻るので、そのファイル名では見つかりませんでした。

同じ書き換えは、WT+ のほかに次の読み込みでも起きていました。

- WT / WT2 の波形
- OPZX7 のオペレーターの WT / WT2
- WT MOD / WT AMP MOD の変調波形

3.6.1 では、読み込んでも**波形フォルダを書き換えない**ようにしました。次に一覧を
開いたときに前のフォルダから始まるのは、これまでどおりです (一覧が自分で覚えて
います)。SETTINGS の「波形フォルダ」が、知らないうちに変わることもなくなります。

**3.6.0 までに保存したプロジェクトやプリセット**は、保存したパスで見つからなければ、
波形フォルダの下、次にプラグインの置き場の下を**名前で探して**読み込みます。
同じ名前のファイルがいくつもあって決められないときは、読み込みません。開き直して
波形が戻っていれば、一度保存し直すと、次からは正しいパスで保存されます。

あわせて、WT+ のタブを開いたままプリセットを読んだとき、スロットの波形と名前が
前のまま残っていたのも直しました。

## ファイルブラウザー

- 周期の切り替え (1 / 2 / 5 / 10) の左に**すべて停止 / すべて再生**ボタンを足しました。
  一覧の行の波形プレビューを、まとめて止める・動かせます
- **初期フォルダ**ボタンを「フォルダ削除」の右に足しました。SETTINGS で決めてある
  置き場へ一息で戻ります
- 「検索」の見出しを足し、キーワード・区分・ファイル形式と一緒に**白い枠**で
  囲みました
- 書き出すときの名前の欄は、見出し・欄・保存ボタンを**灰色の札**に載せました。
  検索の欄と見分けが付きます
- 「名前」「検索」の見出しは太字にし、字を 2 ピクセル大きくしました
- 今いるフォルダを、一覧の上の**青い帯**に出すようにしました
- フォルダの名前を、少し明るい金の**太字**にしました
- 行の波形プレビューを縦 1.5 倍にし、下に**一時停止・シークバー・縦の拡大率**を
  足しました (次の節)

## 波形プレビューの一時停止・コマ送り・縦の拡大

生成波形のプレビュー (リアルタイムの波形プレビューの下) を縦 1.5 倍にし、下に
3 つの操作を足しました。ファイルブラウザーの行のプレビューにも同じものが付きます。

| ところ | はたらき |
| --- | --- |
| ▶ / ❚❚ | 動きを止める・動かし直す |
| シークバー | 1 周期を 1 コマとして、見る位置を選ぶ。押す・引っぱるとその位置へ、ホイールで 1 コマずつ送る (送ると止まる)。真ん中に「今のコマ / 全コマ」。右クリックでフレームの番号を打ち込める (横に全フレーム数) |
| 拡大率 | 波形の縦の振れ幅を x1〜x8 に広げる。枠の高さは変わらない |

ある瞬間の波形をくっきり見たいときに使います。波形ファイルや音声ファイルの
止め絵では、拡大率だけが効きます。
