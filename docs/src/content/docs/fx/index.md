**FX** は、音源が鳴らした音を加工する部分です。音源側ではタブではなく、
**右端に出しっぱなしのペイン**として並んでいます。2686VFX ではこれが本体で、
入ってきた音へ同じものを掛けられます。

## 効果の一覧

| 効果 | 中身 |
| --- | --- |
| [フィルター](/2686V_2686VFX/fx/filter/) | 決めた高さから上か下かを削る |
| [3バンドイコライザー](/2686V_2686VFX/fx/eq3band/) | 低い・真ん中・高いの量を上げ下げする |
| [トレモロ](/2686V_2686VFX/fx/tremolo/) | 音量を周期的に揺らす |
| [ビブラート](/2686V_2686VFX/fx/vibrato/) | 音程を周期的に揺らす |
| [ビットクラッシャー](/2686V_2686VFX/fx/bitcrusher/) | ビット数と間引きで粗くする |
| [ディレイ](/2686V_2686VFX/fx/delay/) | 音を遅らせて繰り返す |
| [リバーブ](/2686V_2686VFX/fx/reverb/) | 広さの響きを足す |
| [SFCエコー](/2686V_2686VFX/fx/sfc-echo/) | 実機ゆずりの、係数で作るエコー |
| [PCMビットクラッシャー](/2686V_2686VFX/fx/pcm-bitcrusher/) | 音源の QUALITY と同じ刻みで粗くする（**2686VFX だけ**） |

2686VFX にはさらに、[出力への変調](/2686V_2686VFX/fx/mod/) があります。音源が 1 音ごとに
持っているエンベロープや LFO を、入ってきた音そのものへ掛けるものです。

プラグインそのものの紹介は
[2686VFX (エフェクト)](/2686V_2686VFX/plugins/fx-plugin/) にあります。

## どの効果にもあるもの

| つまみ | 内容 | 初期値 |
| --- | --- | --- |
| **バイパス** | 入れると、その効果を通さない | オン（通さない） |
| **MIX** | 原音と効果音の混ぜ具合。0.0 で原音のまま、1.0 で効果だけ | 0.0 |

**どの効果も、初めはバイパスが入っていて MIX が 0.0 です。** バイパスを外し、
MIX を上げてから、つまみを触ってください。バイパスを外しただけでは音は
変わりません。

全体をまとめて通さない **バイパス**
（[`FX_BYPASS`](/2686V_2686VFX/reference/automation/fx/#fx-bypass)、初期値オフ）も
別にあります。効果をまとめて外して、元の音と聞き比べるときに使います。

**パラメータリセット** を押すと、この区分のつまみがすべて初期値へ戻ります。

## 掛かる順番

<figure class="shot">
	<img src="/2686V_2686VFX/ui/fx/fx_order.png" alt="FXオーダー" style="width:400px;" />
	<figcaption>FXオーダー</figcaption>
</figure>

効果は上から順に掛かります。**歪ませてから響かせる**か、**響かせてから
歪ませる**かで、出てくる音はまるで変わります。

順番は **設定** の中で入れ替えられます。書き出したものは `.fxo.json`
ファイルになります。

:::note[名前で持っています]
順番のファイルは番号ではなく**名前**で持ちます。効果の数が違うプラグイン
同士でも、位置がずれて別の効果として読まれることがありません。知らない
名前は読み飛ばされます。
:::
