WT・WT2・WT+ チャンネルでそのまま読み込める波形ファイルをまとめました。
描く前の出発点として、あるいはそのまま鳴らす素材としてお使いください。

## ダウンロード

| ファイル | 中身 |
| --- | --- |
| [2686V-wavetables-wt.zip](/2686V_2686VFX/downloads/2686V-wavetables-wt.zip) | **73 個**の `.wt`（値を実数で持つ形式） |
| [2686V-wavetables-wt2.zip](/2686V_2686VFX/downloads/2686V-wavetables-wt2.zip) | **99 個**の `.wt2`（値を段階で持つ形式） |

どちらも自由に使い、改変し、配布できます。

## 読み込み方

| チャンネル | 手順 |
| --- | --- |
| **WT / WT2** | FORM の `[Import]` から読み込みます |
| **WT+** | SLOT ごとの `[WT]` `[W2]` ボタンから読み込みます |

WT+ なら 32 枚まで並べておけるので、まとめて読み込んでスライダーで切り替え
られます。詳しくは [WT+](/2686V_2686VFX/chips/wtplus/) を参照してください。

## 名前の付け方

```text
<分類>_<名前>.wt            例: additive_organ-3.wt
<分類>_<名前>_r<解像度>.wt2  例: additive_organ-3_r32.wt2
```

`.wt2` の `r16` `r32` `r64` は**段の数**です。**小さいほど当時の実機に近い
粗さ**になります。同じ形を解像度違いで用意してあるので、聞き比べられます。

## 分類

| 分類 | 中身 |
| --- | --- |
| `basic` | 正弦波・のこぎり・矩形波・三角波 |
| `pulse` | パルス幅を 6%〜44% まで変えたもの |
| `ramp` | 三角波のピーク位置をずらしたもの |
| `additive` | 倍音を積んだもの。オルガン風・鼻にかかった音など |
| `phase` | 倍音の位相をずらしたもの |
| `formant` | 母音のような響き（あ・い・う・え・お） |
| `metallic` | 整数倍でない倍音。鐘や金属の響き |
| `fold` | 振り切れたぶんを折り返したもの |
| `clip` | 頭を潰したもの |
| `lofi` | わざと段を粗くしたもの |
| `noise` | 周期のあるざらつき |
| `mix` | 基本の形を混ぜたもの |
| `stair` | 段のある形 |
| `detail` | 256 サンプルの細かい形 |

## サンプル数について

32・64・128・256 サンプルのものが混ざっています。**当時の実機は 32 点前後が
普通**でしたので、実機らしさを狙うなら `basic` `pulse` `lofi` `stair`（いずれも
32 点）あたりから試すのが近道です。

`detail` の 256 点は、なめらかな形を作りたいときのものです。

## 形式について

`.wt` と `.wt2` は **3.0.0 でも形式が変わっていません。** 中身はテキストなので、
他の道具で作ったものも持ち込めます。

```text
.wt                    .wt2
32                     32        ← サンプル数
0.000000               8         ← .wt2 は 2 行目が解像度
0.195090               11
...                    ...
```

詳しくは [ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を
参照してください。
