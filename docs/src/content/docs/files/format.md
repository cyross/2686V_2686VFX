## 形式は JSON と YAML から選べます

3.0.0 で、パラメータファイルを**名前で持つ形式**へ移しました。それまでは行の
並び順だけで値を持っていたため、項目を足すと古いファイルが読めなくなり、
並べ間違えると黙って別の値が入っていました。名前で持てばどちらも起きません。

SETTINGS タブの **「ファイル形式」** で JSON と YAML を選べます。

- **JSON** — 既定。読み書きが速い
- **YAML** — 人が読み書きしやすい。手で書き足すこともできる

:::note
**切り替えても、それまでのファイルは読めます。** 読み込みは名前ではなく中身を
見て振り分けているので、拡張子を付け替えられていても読めます。変わるのは
これから書き出すものだけです。
:::

## 置き場所

すべて、ドキュメントフォルダの下の共通フォルダに置かれます。

```text
(ドキュメント)\2686V\
```

| フォルダ | 中身 |
| --- | --- |
| `Presets` | プリセット |
| `Samples` | 読み込んだ音声ファイル |
| `Wavetables` | 波形テーブル (.wt / .wt2) |
| `FxOrders` | エフェクトの並び順 |
| `FxParams` | エフェクトのパラメータ |
| `ChannelParams` | チャンネルのパラメータ |
| `CurveParams` | カーブ |
| `LfoParams` | LFO |
| `AmpEnvParams` | 音量エンベロープ |
| `PitchEnvParams` | 音程エンベロープ |
| `SsgHwEnvParams` | SSG ハードウェアエンベロープ |
| `SsgSwEnvParams` | SSG ソフトウェアエンベロープ |
| `DetuneParams` | デチューン |
| `UnisonParams` | ユニゾン |
| `QualityParams` | 音質 |
| `PcmPlayParams` | PCM の再生 |
| `ToneNoiseParams` | トーン／ノイズ |
| `CustomizeColorSettings` | 配色 |
| `Resources` | 壁紙などの素材 |

このほか、フォルダの直下に次のファイルが置かれます。

| ファイル | 中身 |
| --- | --- |
| `init.settings.json` | 起動時に読む標準設定 |
| `2686V.library.json` | お気に入りと履歴 (プラグインごと) |

:::tip
どちらも、YAML を選んでいるときは `.yaml` になります。起動時には両方を探して、
あるほうを読みます。両方あるときは新しいほうを読みます。
:::

## 拡張子

プリセットはプラグインごとに拡張子が違います。

| プラグイン | 拡張子 |
| --- | --- |
| 2686V | `.2686v.json` |
| 2686VLight | `.2686vl.json` |
| 2686VOrigin | `.86v.json` |
| OPZX7S | `.opzx7s.json` |

パラメータファイルは種類ごとに決まっています。たとえば OPNA のチャンネル
パラメータは `.param.opna.json`、音量エンベロープは `.ampEnv.json` です。

:::caution
**波形データ (`.wt` / `.wt2`) は移行の対象外です。** これらは値の並びではなく
波形そのものなので、今までどおりの形式のままです。
:::

## 3.0.0 より前のファイル

- **プリセット (`.xml`)** — 読み込みだけできます。開いて保存し直すと新しい形式
  になります
- **パラメータファイル** — 読み込むと自動で変換されます。
  [旧形式からの変換](/2686V_2686VFX/files/convert/) を参照してください
