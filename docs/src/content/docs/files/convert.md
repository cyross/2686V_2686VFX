---

3.0.0 より前に書き出したパラメータファイルは、**読み込むだけで変換されます。**
変換専用の画面はありません。

## 手順

1. 変換したい種類のインポートボタンを押します
   (たとえばデチューンなら、オペレータの DETUNE セクションの Import)
2. ファイル選択で古いファイルを選びます。拡張子が `.json` や `.yaml` で
   ないものが古いファイルです
3. 値がその場で読み込まれ、**同じフォルダに新しい形式のファイルが作られます**
4. 「形式を変換しました」の知らせに、元のファイル名と保存先が出ます

たとえば `bass.detune` を開くと、隣に `bass.detune.json` ができます。
保存される形式は SETTINGS の「ファイル形式」に従います。

## 覚えておきたいこと

:::note
**元のファイルは消えません。** 変換は写しを作る動作です。
:::

:::caution
**変換先が既にある場合は書き出しません** (読み込みはします)。同じファイルを
読み込むたびに変換が走るので、変換したあとに手を入れた内容を上書きで戻して
しまわないようにしています。作り直したいときは、先に変換後のファイルを消して
ください。
:::

## 変換できるもの

チャンネル、オペレータ、FX の並び順とパラメータ、各種エンベロープ、LFO、
デチューン、ユニゾン、音質、PCM の再生、トーン／ノイズ、カーブ、リズムの
パッド — **旧形式で書き出せたものはすべて変換できます。**

例外は次の 2 つです。

- **波形データ (`.wt` / `.wt2`)** — 移行の対象外なので、変換の必要がありません
- **プリセット (`.xml`)** — インポートではなく、PRESET タブから普通に読み込め
  ます。読み込んだあと保存し直すと新しい形式になります

他のタブのファイルを読み込む口 (OPL のタブから OPL3 のファイルを読むなど) は
変換しません。**そのファイル本来のタブから開けば変換できます。**
