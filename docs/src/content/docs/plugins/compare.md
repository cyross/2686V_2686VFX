このシリーズには 12 のプラグインがあります。このうち、11 種類は**音を作る音源**で、残る 1 つは、**音を加工するエフェクト**です。

音源どうしは、**収録するタブの数だけが違います。** 共通の画面と操作はすべて同じです。 FX は音源側ではタブではなく、右端に出しっぱなしのペインです（[画面の見かた](/2686V_2686VFX/guide/screen/)）。

## まずはここから

| | ユースケース | プラグイン |
| --- | --- | --- |
| 全部入り | 迷ったとき | 2686V / 2686VLight |
| 当時の構成 | 当時の音源ボードの音で作りたいとき | 26V / 86V |
| FM を掘り下げる | 実機に無い、モダンな FM も試したいとき | OPZX7S |
| パートごとに差す | 曲の中で 1 パートだけ使いたいとき | OPNV / OPLV / OPMV / WTV / PCMV / PULSEV |
| エフェクトだけ | 音源は要らず、加工部分だけ使いたいとき | 2686VFX |

チャンネルを絞ったものは、そのぶん **同時に何本も挿したときの負荷が軽くなります**。パートごとに差して使うことを考えて用意してあります。

### 選び方の目安

- **迷ったら 2686V** — すべて入っています
- **2686VLight** — 2686V からカーブ編集を外したものです。カーブを使わないならこちらのほうが軽く動きます
- **26V** — PC-9801-26(K) に構成を合わせてあります。チャンネルは **OPN と SSG だけ**。初代 98 のころの音で作りたいときに向きます
- **86V** — PC-9801-86 に構成を合わせてあります。ADPCM は **PCM** という名前になり、リズムのパッドは 8 つではなく **6 つ**です。当時の構成で作りたいときに、余計な選択肢が出ません
- **OPZX7S** — モダンなFM音源を試したいとき。**カーブ編集は標準で付きます**

### 選び方の目安

- **[OPNV](/2686V_2686VFX/plugins/opnv/)** — OPNA と OPN。PC-9801 系の FM を 1 パートだけ足したいとき
- **[OPLV](/2686V_2686VFX/plugins/oplv/)** — OPL と OPL3。2 オペレータの軽い音と 4 オペレータの厚い音を行き来したいとき
- **[OPMV](/2686V_2686VFX/plugins/opmv/)** — OPM だけ。X68000 やアーケードの音を 1 パートだけ足したいとき
- **[WTV](/2686V_2686VFX/plugins/wtv/)** — WT・WT2・WT+。波形メモリらしい音のパートを作りたいとき
- **[PCMV](/2686V_2686VFX/plugins/pcmv/)** — RHYTHM と ADPCM と ADPCM+。リズムとサンプル再生をまとめて受け持ちたいとき
- **[PULSEV](/2686V_2686VFX/plugins/pulsev/)** — SSG と BEEP。矩形波のベースやアルペジオを足したいとき
- **[OPZX7S](/2686V_2686VFX/plugins/opzx7s/)** - レトロFM音源を超越したモダンFM音源も嗜みたくなった時

## 唯一存在するエフェクトプラグイン

**2686VFX** だけは毛色が違います。音を作らず、**入力を加工します。** 音源に付いている FX タブを取り出して、単体で使えるようにしたものです。

| | 音源の 11 本 | <img src="/2686V_2686VFX/logos/2686VFX.png" alt="" width="28" height="28" style="vertical-align:middle;" /><br />2686VFX |  |
| --- | :---: | :---: | :---: |
| 種類 | 音源 (シンセ) | エフェクト |
| 音声入力 | なし | ステレオ |
| 音源タブ | あり | なし |
| FX | 8 種類 | **9 種類** |
| 出力への変調 | — | ✔ |
| PRESET タブ | ✔ | — |

詳しくは [2686VFX (エフェクト)](/2686V_2686VFX/plugins/fx-plugin/) を参照してください。

:::note
プリセットの拡張子はプラグインごとに違うので、別のプラグインのプリセットは一覧に出ません。ただし **FX の順番とパラメータのファイルは共通**で、音源と2686VFX のあいだで行き来できます。
詳しくは[ファイルの形式と置き場所](/2686V_2686VFX/files/format/) を参照してください。
:::
